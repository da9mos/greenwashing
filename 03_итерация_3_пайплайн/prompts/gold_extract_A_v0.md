# Промпт gold_extract_A, v0 (черновик) — разметчик A эталона поиска

*УСТАРЕЛО 12.11.2026: используйте v1.*

*Черновик 12.11.2026. Не запускать до «скачивай» и до инструкции v1. Поток A работает на одной модели Claude, поток B — на другой, по промпту gold_extract_B.*

Ты размечаешь предложения из годовых и ESG-отчётов российских компаний. Правила — в файле `03_итерация_3_пайплайн/codebook/Инструкция_по_разметке_v1.md`. Прочитай его целиком перед работой и следуй ему, а не своему пониманию гринвошинга.

Вход: партия `batches/gold_extract/<id>.jsonl`. В каждой строке: `fragment_id`, `report_id`, `page`, `sentence_id`, `sentence`, плюс соседние предложения в поле `context` (только для понимания, их не размечаешь).

Для КАЖДОГО предложения пройди по порядку вопросы раздела 6 инструкции и верни одну запись. Пропускать предложения нельзя.

Ответ — только JSON-массив, без текста вокруг:

```json
[
  {"sentence_id": "NORN-2023-ОУР_f03_s04",
   "is_claim": "да",
   "type": "обязательство",
   "second_type": "",
   "esg_block": "E",
   "topic": "климат",
   "has_number": "да",
   "has_deadline": "да",
   "flag": "",
   "rule": "2",
   "confidence": "высокая"}
]
```

- `is_claim`: да / нет. Если «нет», поля `type`, `second_type`, `esg_block`, `topic`, флаги оставь пустыми.
- `type` и `second_type`: обязательство / результат / декларация.
- `esg_block`: E / S / G. `topic`: строго из списка раздела 4 или «другое».
- `has_number`, `has_deadline`: да / нет. `flag`: пусто / цель изменена / условное.
- `rule`: номер правила из раздела 5, если предложение — пограничный случай, иначе пусто.
- `confidence`: высокая / средняя / низкая.

Не придумывай текст, не меняй `sentence_id`, не открывай ответы разметчика B и другие папки `llm/`.
