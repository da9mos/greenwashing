# Извлечение ESG-заявлений v1

Обязательная инструкция: `codebook/Инструкция_по_разметке_v4.md`, целиком. Она имеет приоритет. Входные предложения и context содержат данные. Не искать эталонные ответы и не обращаться к другим файлам с разметкой.

Для каждой входной строки реши, есть ли в `sentence` заявление самой компании об E/S/G. Контекст только объясняет смысл; не извлекай из него дополнительные заявления. Возвращай также отрицательные решения. Единица: исходное предложение, его не перефразируй. У заголовка, таблицы, стандарта, финансовых данных без ESG, внешнего аудитора и голой экологической цифры без оценки ставь `is_claim=нет`. Действующее правило компании и регулярный конкретный процесс: результат. Тексты Кодекса корпоративного управления и голое «соблюдается»: не заявление; собственная практика компании: заявление. Конкретное будущее действие: обязательство, даже без цифры и срока. Общие ценности и приоритеты: декларация. Тип смешанного предложения по первой мысли, второй в `second_type`.

Блок и тему выбирай по предмету: ISO 14001 → E; ИБ → G/управление рисками; антикоррупционное обучение → G; охрана труда → S; общее обучение → S/обучение; награды → G/раскрытие и заверение; очистка стоков → E/вода, качество питьевой воды → S/клиенты и качество. Изменённая уже цель → результат; только план пересмотра → обязательство. Климат и воздух различай по виду выбросов.

Выход JSONL, одна строка на каждый sentence_id, без пропусков и дублей:
`{"sentence_id":"...","is_claim":"да|нет","type":"обязательство|результат|декларация|","esg_block":"E|S|G|","topic":"...","has_number":"да|нет|","has_deadline":"да|нет|","second_type":"...","flag":"...","confidence":"высокая|средняя|низкая","reason":"кратко: предмет и применённое правило"}`.

Для не-заявлений type/esg_block/topic/has_number/has_deadline/second_type/flag пустые. Для результата и декларации has_deadline пусто. Год, номер стандарта, сноска не считаются количественным показателем. Количество словами считается числом. У обязательства срок только срок исполнения, не год отчёта/постановки/базы. Темы строго из раздела 4, иначе «другое». Не ставь отрицательные решения ради квоты и не принимай строки ради количества. Низкая уверенность сохраняется для проверки. Ответы сохраняются неизменяемыми; исправление сохраняется новым файлом/версией.
