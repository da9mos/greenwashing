Вход: партия `/mnt/project-files/03_итерация_3_пайплайн/batches/gold_extract_A/gold_extract_<партия>.jsonl` (партии: pilot, b01…b08, c01…c03). В каждой строке: `sentence_id`, `report_id`, `page`, `sentence`, `context` (соседние предложения — только для понимания, их не размечаешь).

Выход: сохрани JSON-массив в `/mnt/project-files/03_итерация_3_пайплайн/llm/gold_extract_A/v3/gold_extract_<партия>.json`. Если такой файл уже есть — не перезаписывай, сообщи. Только JSON, без текста вокруг:

```json
[
  {"sentence_id": "NORN-2023-ОУР_f003_s04",
   "is_claim": "да",
   "type": "обязательство",
   "second_type": "",
   "esg_block": "E",
   "topic": "климат",
   "has_number": "да",
   "has_deadline": "да",
   "flag": "",
   "rule": "2",
   "confidence": "высокая"}
]
```

- `is_claim`: да / нет. Если «нет», все остальные поля, кроме `sentence_id`, `rule` и `confidence`, пустые.
- `type` и `second_type`: обязательство / результат / декларация (`second_type` обычно пусто).
- `esg_block`: E / S / G. `topic`: строго из списка раздела 4 или «другое».
- `has_number`: да / нет. `has_deadline`: да / нет у обязательства, пусто у остальных.
- `flag`: пусто / цель изменена / условное / ожидаемый эффект.
- `rule`: номер правила из разделов 5, 8 или 9 (или Н1–Н6 из раздела 2), если предложение — пограничный случай, иначе пусто.
- `confidence`: высокая / средняя / низкая.

Не придумывай текст, не меняй `sentence_id`, не открывай ответы разметчика B и другие папки `llm/`. В конце напиши, сколько предложений размечено и сколько из них заявлений.
