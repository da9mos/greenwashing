# Промпт gold_extract_A, v1 — разметчик A эталона поиска заявлений

*12.11.2026. Заменяет v0 (исправлены пути, добавлен флаг «ожидаемый эффект»). Поток A — одна модель Claude, поток B — другая модель, по промпту gold_extract_B_v1. Ответы A и B друг другу не показываются.*

Ты размечаешь предложения из годовых и ESG-отчётов российских компаний. Правила — в файле `/mnt/project-files/03_итерация_3_пайплайн/codebook/Инструкция_по_разметке_v1.md`. Прочитай его целиком перед работой и следуй ему, а не своему пониманию гринвошинга.

Вход: партия `/mnt/project-files/03_итерация_3_пайплайн/batches/gold_extract_A/gold_extract_<партия>.jsonl` (партии: pilot, b01…b08). В каждой строке: `sentence_id`, `report_id`, `page`, `sentence`, `context` (соседние предложения — только для понимания, их не размечаешь).

Для КАЖДОГО предложения пройди по порядку шаги раздела 6 инструкции и верни одну запись. Пропускать предложения нельзя; число записей = число строк партии.

Выход: сохрани JSON-массив в `/mnt/project-files/03_итерация_3_пайплайн/llm/gold_extract_A/v1/gold_extract_<партия>.json`. Если такой файл уже есть — не перезаписывай, сообщи. Только JSON, без текста вокруг:

```json
[
  {"sentence_id": "NORN-2023-ОУР_f003_s04",
   "is_claim": "да",
   "type": "обязательство",
   "second_type": "",
   "esg_block": "E",
   "topic": "климат",
   "has_number": "да",
   "has_deadline": "да",
   "flag": "",
   "rule": "2",
   "confidence": "высокая"}
]
```

- `is_claim`: да / нет. Если «нет», все остальные поля, кроме `sentence_id`, `rule` и `confidence`, пустые.
- `type` и `second_type`: обязательство / результат / декларация (`second_type` обычно пусто).
- `esg_block`: E / S / G. `topic`: строго из списка раздела 4 или «другое».
- `has_number`: да / нет. `has_deadline`: да / нет у обязательства, пусто у остальных.
- `flag`: пусто / цель изменена / условное / ожидаемый эффект.
- `rule`: номер правила из раздела 5 (или Н1–Н6 из раздела 2), если предложение — пограничный случай, иначе пусто.
- `confidence`: высокая / средняя / низкая.

Не придумывай текст, не меняй `sentence_id`, не открывай ответы разметчика B и другие папки `llm/`. В конце напиши, сколько предложений размечено и сколько из них заявлений.
