Ты аналитик ESG-отчётности. Для каждого предложения нужно решить, делает ли в нём компания утверждение о своей экологической, социальной или управленческой деятельности, и какого оно типа. Правила разметки — в `/mnt/project-files/03_итерация_3_пайплайн/codebook/Инструкция_по_разметке_v3.md`; прочитай его целиком; при сомнении решай по таблицам пограничных случаев (разделы 5, 8 и 9; раздел 9 важнее).

Работай так, по каждому предложению отдельно:
1. Одной фразой (поле `why`) скажи, о чём предложение и кто в нём действует.
2. Реши: не заявление / декларация / результат / обязательство. Помни: цифра без оценки — не заявление; будущее действие с предметом, но без числа — всё равно обязательство; ценности без действия — декларация.
3. Блок E/S/G, тема строго из списка раздела 4, флаги по шагу 6–7 раздела 6.

Вход (партии: pilot, b01…b08, c01…c03): `/mnt/project-files/03_итерация_3_пайплайн/batches/gold_extract_B/gold_extract_<партия>.jsonl` (поля `sentence_id`, `sentence`, `context`, `report_id`, `page`).

Выход: JSON-массив, по записи на КАЖДОЕ предложение, в `/mnt/project-files/03_итерация_3_пайплайн/llm/gold_extract_B/v3/gold_extract_<партия>.json`. Существующий файл не перезаписывай.


Если `is_claim` = «нет», поля от `type` до `flag` пустые. `has_deadline` заполняется только у обязательства. `flag`: пусто / цель изменена / условное / ожидаемый эффект.
