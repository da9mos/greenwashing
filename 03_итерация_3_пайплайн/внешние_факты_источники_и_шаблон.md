# Внешние факты: источники, шаблон, пример заполнения

Задание (критерий 3): перечислить источники, сделать шаблон факта и заполнить его пробно на двух компаниях.

## 2. Шаблон

`templates/external_facts_шаблон.csv` — 12 колонок, разделитель `;`, UTF-8 с BOM (Excel открывает двойным щелчком).

| Колонка | Что писать |
|---|---|
| № | номер факта: `F-КОД-001` (код компании из `companies.csv`) |
| Компания | полное название юрлица, как в отчёте |
| Код | 4 латинские буквы: SHLZ, PIGM |
| Дата события | `ДД.ММ.ГГГГ` — когда произошло, а не когда опубликовано |
| Тип события | штраф / предписание / иск / авария / несчастный случай / инцидент / нет события |
| Что произошло | одна строка: суть и к какому блоку относится |
| Сумма, ₽ | только цифры; пусто, если сумма не раскрыта |
| Источник и где смотреть | кто опубликовал; для отчёта — `отчёт КОД-ГОД-ТИП, стр. N` |
| Ссылка | URL первоисточника; для отчёта пусто (страница указана в «Источник») |
| Цитата дословно | до 300 знаков, ровно как в источнике |
| Блок | E / S / G |
| Связанное заявление | `claim_id` из `claims.csv`, если факт к нему относится |

Правила: факт без ссылки или без страницы отчёта в таблицу не идёт; «ничего не нашли» — тоже результат, `тип события = нет события`.

## 3. Пример заполнения

`data/out/external_facts.csv` — 7 строк по двум компаниям, у каждой есть и внешнее событие, и данные из отчёта.

**АО «Щербинский лифтостроительный завод» (SHLZ)**
- `F-SHLZ-001` — 02.09.2026, штраф (картель): ФАС признала завод участником сговора на торгах по замене 207 лифтов, сумма штрафов всем четырём участникам 17 млн ₽, доля завода не раскрыта; блок G; ссылка на публикацию.
- `F-SHLZ-002` — 31.12.2024, травматизм: LTIFR 0,41 → 0,19 → 0, блок S, отчёт стр. 37; связано с заявлением `SHLZ-2023-015`.
- `F-SHLZ-003` — 31.12.2023, нет события: за два года ни одного смертельного несчастного случая, блок S, отчёт стр. 20.

**АО «Пигмент» (PIGM)**
- `F-PIGM-001`, `F-PIGM-002` — 2023 и 2024, нет события: компания заявляет, что предписаний и штрафов по экологии не было (стр. 24 и 34). Это проверяемое утверждение — именно его и должен проверять внешний источник.
- `F-PIGM-003`, `F-PIGM-004` — штрафы по другим направлениям: 0,7 млн ₽ за 2023 (стр. 103) и 0,95 млн ₽ за 2024 (стр. 28), блок G. Смешивать с «экологическими» нельзя: в отчёте это разные строки.

Все шесть цитат из отчётов сверены с текстом на указанных страницах — совпадают дословно.

## Что осталось

- Прогнать по остальным компаниям тем же шаблоном: 2–4 факта на компанию, минимум три типа источников в сумме.
- Сайты с капчей (`kad.arbitr.ru`) и закрытые с рабочей машины (ФАС, Ростехнадзор, Роструд) открывать вручную с российского IP; капчу не обходим.
- ИНН ЩЛЗ и Пигмента в отчётах не указаны — если понадобится для поиска в реестре проверок, добавить вручную.
