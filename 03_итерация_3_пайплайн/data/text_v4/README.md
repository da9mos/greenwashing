# Тексты отчётов v4: шрифт и дефисы по самим PDF

*16.11.2026, вечер. Сделано по независимой проверке текстов v3. **v4 — действующая версия.** Старые версии не тронуты: v2 (`data/pages`, `data/chunks`, `claims.csv`, `gold_extract.csv`) и v3 (`data/pages_v3`, `data/chunks_v3`, `*_text_v3.csv`, помечена «УСТАРЕЛО»). Какую версию берут скрипты, задаёт `src/text_versions.py`.*

Потом PDF разобран заново с полной таблицей (файл PDF не меняется). Исправлено 17 979 знаков в 73 частях шрифта; «№» в тексте 231 раз (в v3 — 99). ### Как решены 150 276 переносов

| довод | слитно | через дефис | другое |
|---|---:|---:|---:|
| это же слово внутри строки в PDF | 127 810 | 4 890 | |
| однокоренные слова внутри строки в PDF | 768 | 253 | |
| мягкий перенос в PDF | 15 164 | | |
| правило (такого слова в PDF внутри строки нет) | 942 | 241 | висячий дефис 69, оставлен перенос строки 139 |

«Оставлен перенос строки» — когда после дефиса идёт слово с заглавной: сверка показала, что это почти всегда строка из соседней колонки или заголовок («уча-» + «Цепочка поставок»). Такое место не склеивается и дефис не придумывается: текст остаётся как в PDF (дефис и конец строки).

## Как проверено

**Автотесты** (`tests/test_text_v4.py`, 31 тест всего проекта проходит): нет значков битого шрифта в ММК 2025, на стр. 108 «№ 12», «V», «III–IV», нет «JUL»; известные слова стоят как в PDF («рискориентированного», «Новосакмарского», «социально-экономическое», «нитрит-нитратные», «аудиосказок» в RVDK-2025 и «аудио-сказок» в RVDK-2024 — как в каждом PDF); каждое решение с доводом из PDF совпадает с большинством написаний в PDF; буквы v4 те же, что в v2, кроме убранных колонтитулов; не появилось дефисов сверх решений «через дефис»; нет мягких переносов; позиции переносов сверяются с текстом (иначе сборка останавливается); скрипты не берут тексты мимо `text_versions.py`; pymupdf закреплена на 1.28.2; каждая цитата заявлений и эталона стоит на своей странице v4 дословно, метки не изменились.

**Сверка с PDF другим разборщиком** (pdftotext, свежая случайная выборка, зерно 20261116; `src/check_v4_pdf.py`, итог `сверка_PDF_итог.md`):

- Страницы: 270 (по 3 из каждого отчёта с PDF). Совпали по буквам 264. Ещё 5 — так же было в v2: в PDF есть второй, скрытый слой текста (например, таблицы «Северстали» 2023), который PyMuPDF не выдаёт; 1 — ММК 2025, где pdftotext сам видит битый шрифт.
- Цитаты: 300 (150 заявлений и 150 предложений эталона). 294 стоят на той же странице PDF подряд, у 5 все слова на той же странице, но pdftotext читает колонки в другом порядке, 1 — ММК 2025.
- Переносы: 300 мест глазами, по 60 в группе. По доводу из PDF — ошибок не найдено. Слитно по правилу — 3–5 спорных из 60 («игрушкойсимволом», «брендзона», «тревелблогинг»; «выявобщий» — склейка двух колонок). Через дефис по правилу — 4 спорных из 60 («потребителей-дополнительно» из соседней колонки; «IT-и» вместо «IT- и»). Оставлен перенос строки — у части это настоящие составные названия («Азовско-Черноморского», «Тайшет-Энергия»), но буквы и дефис на месте, вместо дефиса без пробела стоит дефис и конец строки. Висячий дефис и мягкий перенос — ошибок не найдено.

Оценка по корпусу: спорных решений около 100 из 150 тыс. переносов, все — среди 1 391 решения по правилу; каждое видно в `переносы.csv` (колонка `довод` начинается с «в PDF нет»).

## Как пересобрать

Из папки `03_итерация_3_пайплайн`. Готовые файлы скрипты не перезаписывают. Модель не нужна.

```
pip install -r requirements.txt                    # pymupdf==1.28.2, нужна только для шага 1
python -I src/pdf_evidence_v4.py <папка с PDF>      # переносы.csv, база ММК 2025, таблица шрифта (нужны PDF)
python -I src/clean_text_v4.py                      # data/pages_v4 (PDF не нужны)
python -I src/chunk.py pages_v4 chunks_v4
python -I src/migrate_to_v4.py                      # claims_text_v4.csv, gold_extract_text_v4.csv
python -I src/check_v4_pdf.py <папка с PDF>         # сверка с pdftotext (нужен poppler-utils)
python -m unittest discover -s tests -v
```

Шаг 1 сам проверяет, что разбор каждого PDF совпадает с v2 символ в символ, и останавливается, если нет (другая версия pymupdf).

## Что осталось

- **ТМК 2023:** часть шрифта Roboto без таблицы знаков, номера знаков перенумерованы — заголовки и часть страниц остаются набором значков. Отчёт помечен «проверить». Нужен разбор картинки страницы.
- **Таблицы:** числа идут столбиком и отрываются от подписей, как в v2 и v3. Для «Динамики» нужен отдельный разбор таблиц.
- **Скрытый второй слой текста** в некоторых PDF (таблицы «Северстали» 2023 и др.): PyMuPDF его не выдаёт, pdftotext выдаёт. На заявления не влияет.
- **Колонки:** там, где PDF хранит строки соседних колонок вперемешку, перенос может «склеиться» с чужой строкой; около 140 таких мест оставлены как в PDF.
