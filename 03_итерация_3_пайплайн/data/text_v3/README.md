```
python -I src/clean_text_v3.py          # data/pages -> data/pages_v3 + отчёты в data/text_v3
python -I src/chunk.py pages_v3 chunks_v3
python -I src/affected_v3.py            # какие заявления и предложения эталона задевает чистка
```

Готовые папки скрипты не перезаписывают. Модель не нужна.

## Как проверено (16.11.2026, вторая проверка)

- Пересборка с нуля на чистой копии даёт те же файлы.
- ММК 2025: на стр. 12 все 28 чисел совпали с картинкой страницы, на стр. 110 и 157 текст совпал по словам; значков-цифр было 6 030, осталось 0.
- Дефисы: на 10 PDF из 396 восстановленных дефисов 388 стоят в PDF так же (через дефис или перенос), 8 в PDF написаны слитно (≈2 %).
- Колонтитулы: на 11 PDF из 5 751 убранной строки 37 (0,6 %) стоят не у края страницы; это в основном вкладки меню посреди разворота.

## Что осталось

- **ММК 2025:** на 11 страницах остались значки сносок (армянские буквы) и латиница со сдвигом в некоторых подписях («JUL» вместо «GRI», «FR» вместо «CO»). Отчёт помечен «проверить».
- **ТМК 2023:** заголовки и часть страниц — мусор, заменой не чинится. Нужен повторный разбор другим инструментом (pdftotext часть заголовков читает) или распознавание картинки.
- **Газпром 2024:** значки из шрифта с иконками на 11 страницах (оглавление и плашки), основной текст в порядке.
- **Мосводоканал 2023 и 2025:** номер страницы — печатный, PDF нет; страницы 68–69 MVDK-2025 в тексте отсутствуют (вероятно, картинки).
- **Таблицы** этой чисткой не исправлены: числа по-прежнему идут столбиком и отрываются от подписей. Для «Динамики» цифры нужно брать отдельным разбором таблиц.
- Дефис возвращается по словарю корпуса, а не по PDF, поэтому изредка он может встать там, где автор писал слитно. Каждое такое слово есть в `замены_дефис.csv`.
