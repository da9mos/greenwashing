# Стартовый список внешних источников для фактчекинга

Агент начинает проверку с этого списка и только при необходимости расширяет
поиск. Список сгруппирован по четырём обязательным категориям риска и по
направлению «подтверждение». Для каждого источника указано, что именно там
искать и чем он полезен.

> Общее правило доступа: сайты `.gov.ru` и агрегаторы правовых данных
> (`kad.arbitr.ru`, часть страниц ФАС и Ростехнадзора) с зарубежного IP могут
> отдавать 403/451 или капчу. Если первоисточник не открылся — фиксируй
> `blocked` с реальным `tool_ref` и причиной, используй доступную альтернативу
> (СМИ, кэш, републикацию) и явно указывай, что закрытый реестр прочитан не был.
> Капчу не обходить.

---

## 1. Росприроднадзор — `rosp_enforcement` (блок E)

- **rpn.gov.ru** — новости территориальных управлений (штрафы, предписания,
  плата за НВОС). Поиск по сайту работает через JS (`/search/?q=` отдаёт пустую
  страницу): листать ленту региона параметром `?PAGEN_1=N`.
  Шаблон запроса: «[юрлицо/завод] Росприроднадзор штраф / предписание / разлив /
  выброс / ущерб».
- **ФГИС «Надзор»** — https://nadzor.rpn.gov.ru/ (реестры проверок и предписаний).
- **Плата за негативное воздействие на окружающую среду (НВОС)** — разделы
  отчётов компаний о плате за НВОС (это «ноль — тоже факт», проверяемый без
  интернета по тексту отчёта).

## 2. Ростехнадзор — `rost_enforcement` (блоки E, S)

- **gosnadzor.ru** — сведения об авариях и инцидентах на опасных
  производственных объектах, реестры проверок, предписания по промышленной
  безопасности.
- **Разделы отчётов компаний** об авариях, травматизме, инцидентах (LTIFR,
  число погибших/пострадавших) — проверяемый первоисточник без интернета.

## 3. Судебная практика — `court_cases` (блоки E, S, G)

- **sudact.ru** — судебные акты по названию юрлица или ИНН (арбитраж, общая
  юрисдикция).
- **kad.arbitr.ru** — картотека арбитражных дел. Только вручную (капча, не
  обходить).
- **ГАС «Правосудие»** — sudrf.ru / суды регионов.
- **Единый федеральный реестр сведений о банкротстве** — bankrot.fedresurs.ru.

## 4. Аварии и инциденты в СМИ — `media_incidents` (блоки E, S, G)

- **Интерфакс** — interfax.ru
- **ТАСС** — tass.ru
- **РИА Новости** — ria.ru
- **Ведомости** — vedomosti.ru
- **РБК** — rbc.ru
- **Коммерсантъ** — kommersant.ru
- **Региональные СМИ** — по названию завода/города + «разлив», «выброс»,
  «авария», «несчастный случай», «забастовка», «штраф».

## 5. Прочие надзорные и регистры (блоки S, G)

- **Роструд / ГИТ** — rostrud.gov.ru, онлайн-инспекция: охрана труда,
  предписания трудовых инспекций, несчастные случаи (S).
- **ФАС России** — fas.gov.ru: картели, сговоры, штрафы за нарушение
  конкуренции (G). Часть страниц отдаёт 451 с зарубежного IP.
- **ЦБ РФ** — cbr.ru: нарушения на рынке ценных бумаг, раскрытие информации (G).
- **proverki.gov.ru** — Единый реестр проверок (поиск по ИНН юрлица).
- **ГИР БО / ФНС** — bo.nalog.ru, nalog.ru: бухгалтерская отчётность юрлица,
  проверка ИНН (для суммы, выручки, расходов).
- **ЕГРЮЛ** — egrul.nalog.ru, rusprofile.ru: реквизиты и статус юрлица.

## 6. Подтверждение (support) — первичные и официальные источники

- **Сам отчёт компании** (PDF/Markdown из `data/pages_v4`) — разделы о штрафах,
  плате за НВОС, авариях, травматизме, судебных спорах. Самый дешёвый и
  проверяемый источник: цитата + страница проверяются без интернета.
- **e-disclosure.ru** — Центр раскрытия корпоративной информации (годовая и
  бухгалтерская отчётность, существенные события).
- **РСПП (rspp.ru)** — Национальный регистр корпоративных нефинансовых отчётов,
  реестры ESG-отчётности.
- **Официальный сайт компании** — пресс-релизы, политики, реестры документов
  (для проверки объявленных обязательств и закреплённых политик).

## 7. Международные и агрегаторы (контекст, поддержка)

- **IEA** — iea.org: выбросы, метан, сравнение энергоресурсов за жизненный цикл.
- **OPEC** — opec.org: доказанные запасы, статистика (Annual Statistical Bulletin).
- **Violation Tracker Global** — violationtracker.goodjobsfirst.org: записи о
  нарушениях российских компаний.
- **World Bank / UN** — data.worldbank.org: страновые ESG-показатели.

## Порядок работы со списком

1. Начни с четырёх обязательных категорий риска (п. 1–4) — по одному реальному
   завершённому поиску каждой категории, по соответствующему юрлицу/Группе и
   периоду.
2. Для подтверждения чисел/фактов сначала смотри сам отчёт компании (п. 6),
   затем независимые регистры и СМИ.
3. Один набор поисков можно честно переиспользовать для нескольких заявлений
   того же периметра; дату поиска при этом не подделывать.
4. Ноль результатов — тоже результат: фиксируй пустой `source_ids` с
   `outcome_note`.
