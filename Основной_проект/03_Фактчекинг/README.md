# Фактчекинг

[Рабочая инструкция и команды](Агент/README.md) · [инструкция исследователя](Агент/FACT_CHECK_AGENT.md) · [научные статьи](Научные_статьи/README.md).

На входе JSON заявлений одного отчёта, на выходе реестр тех же утверждений с проверкой и обоснованием. `prepare` создаёт неизменяемый вход, `next` выбирает запись, `ingest` проверяет результат исследователя, `export` собирает рабочие итоги. Поиск выполняет исследователь с веб-доступом по инструкции. Скрипт проверяет структуру, сопоставимость и наличие доказательств. Продолжайте с незавершённых записей из сохранённой рабочей папки.
