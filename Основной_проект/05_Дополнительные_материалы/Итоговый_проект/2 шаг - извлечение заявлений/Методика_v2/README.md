# Методика ESG-разметки v2

17.11.2026. Подготовлена для агента сбора ESG-заявлений проекта Сбер.

- [Научное обоснование](Научное_обоснование.md): пять первичных исследований, международные стандарты, ограничения переноса на русский корпус, полнота извлечения и измерение качества.
- [Кодбук](Кодбук.md): две оси классификации, девять базовых сочетаний, 22 пограничных примера, таблицы и показатели, неопределённость, исключения и независимая разметка.

Исследования и стандарты используются как основания проектных решений. Данная подборка является целевым обзором первичных источников, а не систематическим обзором всей литературы. Правила кодбука не означают, что разметка всего корпуса уже выполнена или её полнота измерена.

В обзоре различаются источники, которые прочитаны непосредственно, авторские карточки данных и статья, полный текст которой был недоступен. ESRS 2023 используется как фиксированная исследовательская версия; документ не подтверждает актуальное юридическое соответствие организации.

Критическая граница: совпадение цитат с Markdown и учёт всех страниц не доказывают полноту извлечения. Для recall нужен независимо размеченный исходный материал с учётом пропусков.
