# Примеры исходников для дальнейшей аналитики

- [Газпром 2023: социальный отчёт](Газпром%202023%20-%20социальный%20отчёт/report.md) – 136 PDF-страниц
- [Газпром 2023: экологический отчёт](Газпром%202023%20-%20экологический%20отчёт/report.md) – 84 PDF-страницы

В каждой папке только report.md и assets. В report.md сохранены все страницы выбранной транскрипции. В assets находятся изображения оригинальных страниц: они сохраняют графику и дают проверить неоднозначные места. Это один текстовый исходник, а не сотни отдельных MD.

Для следующего аналитического ИИ передавайте report.md; при работе с изображениями – всю папку примера. Названия, таблицы, сноски и маркеры страниц находятся в самом MD. Примечания обработки обозначены отдельно.

Это реально полученные ранее результаты с адресными исправлениями, переупакованные в утверждённый формат. Повторная обработка PDF через API в этой задаче не выполнялась. Исторический прогон использовал отдельно разрешённый DeepSeek и проверку по оригиналам; универсальный агент по умолчанию остаётся локальным.

Технический контроль и ограничения расположены в ../_проверка. Примеры не объявляются полностью посимвольно проверенными по PDF: наличие всех страниц и корректная упаковка не доказывают точность каждой ячейки.
