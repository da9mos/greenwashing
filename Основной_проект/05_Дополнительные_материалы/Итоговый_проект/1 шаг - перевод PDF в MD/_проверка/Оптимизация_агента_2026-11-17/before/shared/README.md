# Перевод PDF в Markdown

[Открыть инструкцию](PDF_TO_MD_AGENT.md)

Передайте инструкцию агенту вместе с исходным PDF и укажите папку результата. Нужны доступ к файлу, средства извлечения и возможность проверить сложные участки по изображениям.

Результат: один `report.md` и необходимые `assets/`. Сохранённые реестры, промежуточные результаты и протоколы помещаются отдельно в `_проверка/`. Пустые папки и дополнительные файлы без необходимости не создаются.

Агент извлекает содержание, сверяет его по оригиналу, исправляет ошибки и проверяет итоговое отображение. По умолчанию обработка локальная; внешняя передача требует разрешения. Нерешённые места отмечаются рядом с соответствующим содержанием.

Новые классы ошибок закрепляются через причину, способ обнаружения, действие и контрольный сценарий. Обновление инструкции не подтверждает точность ранее сконвертированных документов.

## Доработка 17.11.2026

Актуальная схема: DeepSeek переносит исходную страницу, Codex независимо проверяет и исправляет подтверждённые дефекты по PDF. Инструкция и ERROR_RULES синхронизированы с [проектной версией](../../11_Проект_Сбер/Итоговый%20проект/1%20шаг%20-%20перевод%20PDF%20в%20MD/Агент/README.md).

Добавлены контроль всех зон, полных таблиц и сносок, сохранение реквизитов, раздельная навигация, координатная привязка увеличений и строгий учёт evidence для checked. Старые QA.md/INDEPENDENT_REVIEW.md являются историей и не подтверждают новую версию. Новые результаты описаны в проектной проверке. Старые инструкции сохранены в history; frozen-снимки работающих/завершённых прогонов не заменялись.
