# Служебная проверка первого шага

Эта папка не нужна как основной вход аналитического ИИ.

- Примеры.json: происхождение 220 страниц, исходные/итоговые хеши текстов и 355 изображений
- Исправления при сборке.csv: четыре адресные правки по оригиналу
- Независимая проверка.md: отдельная сверка упаковки и ограничений
- Проверка инструкции.json: 17 искусственных сценариев следования правилам; это не новый прогон PDF и не доказательство качества всех моделей
- Проверка сборки.json: техническая целостность итоговых файлов и ссылок
- Просмотр/: локальные HTML-предпросмотры для проверки отображения

Канонический агент находится в общих инструментах; проектная копия должна совпадать с ним. Наличие примеров не переводит все их блоки в статус проверенных по PDF. Внешние адреса ссылок восстановлены из аннотаций PDF; их текущая HTTP-доступность этим не подтверждается.
