## Что показано на примере

Один экологический отчёт Газпрома за 2023 год, три типа: обязательство, результат и декларация. Точные цитаты визуально сверены с изображениями физических PDF-страниц 37, 14 и 7; печатные страницы 35, 12 и 5 указаны отдельно.

Обязательство и результат получили открытый вывод «недостаточно данных»: независимые доказательства исполнения и расходов в данном примере не собраны. Декларация получила «декларативно» как характеристику формулировки. Ни одна запись не объявляет доказанный гринвошинг. Тип заявления и итоговая оценка находятся в разных колонках.

Смысловую оценку выполнил Codex в текущей сессии. CLI проверяет цитаты, хеш исходника и контракт доказательств; не запускает LLM и не классифицирует истинность автоматически. Подготовленный вход нужно передать агенту в сессии Codex вместе с инструкцией. Это проверенный демонстрационный проход по трём заявлениям, а не обработка всех 92 отчётов или доказательство точности модели.

## Запуск

Открой терминал в этой папке. Подготовь вход для Codex:

```bash
python3 Агент/assess_claims.py prepare --report '../1 шаг - перевод PDF в MD/Результаты работы/Газпром 2023 - экологический отчёт/report.md' --output 'Рабочий_пакет_нового_прогона'
```

Агент читает `prompt.md` подготовленного пакета и сохраняет новую оценку в JSON по образцу. Подготовка не означает выполненный модельный проход. После оценки проверь и выгрузи CSV:

```bash
python3 Агент/assess_claims.py validate --report '../1 шаг - перевод PDF в MD/Результаты работы/Газпром 2023 - экологический отчёт/report.md' --assessment Пример/Газпром_2023_три_типа.json
python3 Агент/assess_claims.py export --report '../1 шаг - перевод PDF в MD/Результаты работы/Газпром 2023 - экологический отчёт/report.md' --assessment Пример/Газпром_2023_три_типа.json --csv Пример/Газпром_2023_три_типа.csv
python3 -m unittest discover -s Агент -p 'test_*.py' -v
```

Код возврата 0 означает успешную подготовку/проверку; 2 означает ошибку входа или контракта. CSV сохраняется с `;` и UTF-8 BOM. Повреждённая оценка не экспортируется. Для переноса сохраняй весь «Итоговый проект», чтобы относительный путь к исходному отчёту остался рабочим.

Историческая методика и реестр источников остаются в `../../3_итерация/greenwashing/03_итерация_3_пайплайн/stage2_claim_assessment/`; их наличие не доказывает выполнение старых прогонов.
