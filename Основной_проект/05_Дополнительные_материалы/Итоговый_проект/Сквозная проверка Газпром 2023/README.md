# Сквозная проверка экологического отчёта Газпрома за 2023 год

Рабочий комплект связывает существующий перевод PDF, классификацию по методике ESG 3.1 и внешний фактчекинг. Итог отчёта и степень его проверки видны в Excel. Вердикты относятся к конкретным утверждениям.

## Инструкции для этапов

1. **PDF → Markdown.** Начать с существующей инструкции PDF_TO_MD_AGENT.md. Передавать следующему агенту физический номер страницы, дословный транскрипт и оригинал. Страницы с редким текстовым слоем прогнать через OCR. Непустой OCR при пустом текстовом слое требует визуальной сверки. На таких страницах особо проверить приложение, оговорки и объём заверения. Сверять каждое число в составе ячейки и её заголовков. Зафиксировать хеш PDF и MD.
2. **Заявления и классификация.** Применять правила ESG 3.1 вместе с научным аудитом 28 источников и уточнениями из научного модуля. Для каждого блока установить субъект, пропозицию и предмет. Единица извлечения — самостоятельный тезис. Тип, основную букву и дополнительные темы оценивать независимо. По таблицам сохранять шапку, строку и примечание. Отсутствие определённого предмета оставляет запись на разбор. В основе тематической разметки — исследовательские примеры FinBERT и ESG9. Выбор основной буквы для смешанных случаев, включение всех неблагоприятных результатов и правила разделения тезисов — соглашения проекта.
3. **Факты и гринвошинг.** Сначала сформулировать проверяемую часть. Зафиксировать организацию, период, показатель, единицу и периметр. Проверить источники как в поддержку, так и в опровержение. Для публикации установить первичное происхождение данных. Приложить ссылку, дату, цитату и указатель места. Если период или периметр расходятся, описать расхождение. Для обещания отдельно проверить договорную дату и факт исполнения. Для нескольких существенных частей вынести отдельные решения. Для гипотезы гринвошинга по Delmas и Burbano, Lyon и Montgomery зафиксировать заявленное впечатление, противоречащий факт и механизм. Отрицательный результат, декларация или отсутствие данных сами по себе такого вывода не дают.

Репозиторий методики расположен в `../../3_итерация/greenwashing_esg_v3/Агент определитель ESG + анализ статей`. Первичный классификационный файл `classified.json` сохраняет основания, спорные записи и ссылку на источник. Журнал `external_research.json` содержит выполненные поиски и оценку независимости источников. Для решающего вердикта `pipeline.py` принимает `parts` со связанной проверенной доказательной базой по каждой существенной части.

## Повторить прогон

```sh
python3 -m unittest discover
python3 pipeline.py --classified classified.json --research external_research.json \
  --independent independent.json --as-of 2026-11-18 --output first_pass.json
python3 pipeline.py --classified classified.json --research external_research.json \
  --independent independent.json --as-of 2026-11-18 --reconcile --ocr --output reconciled.json
```

Для сборки Excel запустить `build_excel.mjs` из каталога с доступным `@oai/artifact-tool`. Передать пути к `reconciled.json`, выходному XLSX и PNG-превью. Скрипт заново импортирует книгу и сверяет все значения листа «Заявления».

## Критерий приёмки

Отдельный проход по оригинальному PDF должен закрыть все страницы, сохранить независимый список и объяснить расхождения с основным извлечением. Каждая числовая строка требует сверки с исходной страницей. Каждый решающий внешний вывод требует проверки доказательства и его применимости. Непрочитанные блоки, необработанные строки и неподтверждённые источники остаются открытыми. Машинный независимый проход и экспертная проверка человеком указываются раздельно.

OCR восстановил машинно читаемый текст приложения на страницах 76–79. Статус OCR требует визуальной сверки. В независимом проходе были проверены пять строк таблицы целей на странице 13. Остаток буквальных несовпадений включает эти пять строк, где в PDF данные лежат в раздельных ячейках, и семь фрагментов с разной сегментацией, переносами или написанием единиц. Сопоставление этих фрагментов не закрывает вопрос атомарности записей.

Из независимой проверки добавлены пять утверждений, пропущенных первым извлечением. Они касаются состава выбросов, нормативно чистой воды, видов отходов и показателя удельного расхода энергии. На странице 14 выделены отдельно величина расходов и пояснение их роста. На странице 38 восстановлен исследованный фрагмент с итогом проверок. Обе привязки отражены в повторном Excel.

Внешний поиск выполнен по четырём заявлениям. Для трёх пока недостаточно сопоставимых доказательств. Одна общая декларация не содержит проверяемого критерия. Например, сообщение регулятора о 26 нарушениях на одном предприятии не устанавливает итоговое число 517 нарушений по Группе. [Регуляторное сообщение](https://rpn.gov.ru/press/news/v_khode_proverki_ooo_gazprom_neftekhim_salavat_rosprirodnadzor_vyyavil_26_narusheniy_obyazatelnykh_t/)

**Приёмка открыта.** Независимый агент технически инвентаризировал 84 страницы и семантически разобрал 61 кандидатный фрагмент на 21 странице. В его журнале 1 043 текстовых блока ожидают содержательного разбора. В книге 100 строк ожидают решения по E/S/G, 773 ожидают внешнего поиска. 235 записей не дали цельного совпадения с текстовым слоем PDF и требуют отдельного чтения оригинала. Полная визуальная сверка чисел, сверка всей выборки и экспертная проверка человеком остаются открытыми.

Пользовательский Excel содержит один лист «Заявления» с шестью столбцами. Из него убраны 58 необработанных Markdown-таблиц. Числовые утверждения, уже изложенные словами, сохранены. Номера соответствуют записям в `reconciled.json`, где доступны исходные фрагменты и материалы проверки. Фильтры и закреплённый заголовок сохранены.
