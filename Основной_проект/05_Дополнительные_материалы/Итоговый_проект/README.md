ZIP-части каждого отчёта — самостоятельные архивы. Скачайте все части одного отчёта и распакуйте в одну папку; сохранится report.md с assets. Финальная сверка доставки не является смысловой проверкой всех отчётов. Удалённые хэши содержимого коннектор не предоставляет; сверены метаданные, а локальная упаковка ранее проверена по SHA-256.

Этап 2 содержит три типа заявлений одного отчёта Газпрома: обязательство, результат, декларация. Смысловая оценка выполнена Codex, программная обвязка проверяет цитаты и контракт доказательств. Пройдены 17 регрессионных тестов. Полная смысловая проверка корпуса и внешнее подтверждение двух конкретных утверждений не завершены.

Здесь собирается итоговая рабочая структура проекта. Первый шаг готовит исходники для дальнейшего анализа заявлений: один Markdown-документ с содержимым отчёта и необходимые изображения рядом.

Папки предыдущих итераций сохраняются как история, исходные данные и доказательства выполненных экспериментов.
