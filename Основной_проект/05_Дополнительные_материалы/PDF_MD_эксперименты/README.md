# PDF → Markdown: DeepSeek и Codex

Новый прогон по 92 отчётам 30 компаний, включая Газпром. Состояние каждого RID — в [живом статусе](СТАТУС.md). **Полная независимая сверка корпуса не подтверждена.**

Сравниваются два процесса, а не симметричный benchmark моделей:

- **Codex v2** работает с PDF и инструментами извлечения текста, изображений и структуры документа; отдельный контроллер поддерживает от одного до трёх рабочих слотов (по умолчанию два)
- **DeepSeek v3** выполняет постраничную визуальную транскрипцию. Адаптер передаёт полный растр страницы, перекрывающиеся увеличенные области, текстовые блоки и числовые PDF-span с размером шрифта, flags и bbox; затем ответы собираются в Markdown

Основная [замороженная инструкция](_проверка/Инструкция_на_старте.md) у обеих веток одна и та же. В v3 изменён адаптер входов DeepSeek. Ответы другой модели не используются как исходник. Версии активных веток читаются из `_проверка/job.json`, отдельно состояние Codex — из `_проверка/codex_controller.json`.

Различия инструментов, контекста и сборки влияют на результат. Доля расхождений текста или чисел не является точностью модели. PDF-текстовый слой тоже может содержать дефекты.

## История: ранние ответы не являются финальными

1. **V1 остановлен:** в ответе появилась ссылка на несуществующий asset. Raw и исходные ответы сохранены
2. **DeepSeek v2 — ранний черновик:** на PDF-странице 57 социального отчёта Газпрома 2023 подтверждены три изменения чисел. Число 1,963 было ошибочно передано как 1,96³; у 0,173 и 76,6 неверно отделены сноски. Два MD перемещены в `DeepSeek_v2_черновик/`, не удалены; raw v1/v2 сохранены
3. **Исправленный пилот:** полный растр + перекрывающиеся увеличения + геометрия числовых span позволили правильно передать значения и сноски на этой странице. Десятичное сравнение всей страницы57 с отдельными PDF-span не обнаружило расхождений. Это подтверждение одного пилота, не готовности всего корпуса
4. **Активный запуск:** DeepSeek v3 и независимый Codex v2. Существующие файлы и протоколы видны в живом статусе; ранние v2-черновики не входят в счётчики DeepSeek v3

Доказательства пилота: [ответ](_проверка/pilot_geometry/answer.json), [исходный ответ API](_проверка/pilot_geometry/raw.json), [входы и хэши](_проверка/pilot_geometry/input.json), [код воспроизведения](tools/probe_geometry.py). Запуск пилота обращается к API; для просмотра доказательств его повторять не требуется.

[Существующее сравнение](_проверка/comparison.md) и [адресная сверка чисел](_проверка/comparison_numeric_spotcheck.md) относятся к ранним двум MD DeepSeek v2. Это история обнаружения дефекта, не итог активной пары DeepSeek v3 / Codex v2. Активное сравнение будет пересчитано по новым файлам; статус дополнительно проверяет совпадение их хэшей со снимком.

## Значение статусов

- **MD существует:** файл есть; это не подтверждает полноту или верность
- **assembled:** соответствующий текущим входам комплект собран и прошёл структурный контроль
- **transcription_complete:** протокол не оставляет незавершённых страниц транскрипции; самостоятельная сверка ещё может отсутствовать
- **checked:** выполнена полная сверка заявленного объёма с оригиналом; сборщики и статусный скрипт его не присваивают
- **pending:** нет исходника, ответа, комплекта или достаточного подтверждения этапа

## Файлы

- `_источники/<RID>.pdf` — исходные PDF; происхождение, SHA и физические страницы — в `_проверка/sources_manifest.json` и `sources.csv`
- `_проверка/входы/<RID>/` — изображения страниц и пакеты текстовых блоков/координат
- `_проверка/DeepSeek/<RID>/v3/` — ответы активного DeepSeek; `_проверка/Codex/<RID>/v2/` — протоколы активного Codex
- `DeepSeek/<CID>/<RID>/report.md` и `Codex/<CID>/<RID>/report.md` — текущие результаты; живой статус ссылается только на существующие файлы
- `DeepSeek_v2_черновик/` — сохранённые ранние MD, отделённые от активных результатов
- `_проверка/comparison*` — структурные и постраничные диагностики с доказательствами числовых расхождений; не итоговая оценка качества

## Продолжение двух контроллеров

Из этой папки, только если соответствующий контроллер уже не работает:

```bash
python3 tools/run_deepseek_v3.py --engine DeepSeek --workers 16
python3 tools/run_codex_independent.py --workers 2
```

Не запускайте второй экземпляр поверх работающего контроллера. Старый `run_models.py --engine both` не является командой продолжения текущей пары версий.

Обновить локальную диагностику и статус:

```bash
python3 tools/compare_results.py
python3 tools/update_status.py
python3 -m unittest discover -s tools -p test_compare_results.py -v
```

`update_status.py` читает версии из метаданных, считает только ответы активной версии DeepSeek и сохраняет проверки хэшей инструкции, исходного изображения, пакета и fingerprint запроса. Устаревший снимок сравнения не засчитывается активной паре. Инструменты проверки не исправляют Markdown моделей и не повышают статус до checked.
