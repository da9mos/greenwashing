# Повторяемые ошибки

1. Вложенные рамки и подчеркивания могут создавать фиктивные ячейки и выносить текст из таблицы. Признак: пустые колонки и строки рядом с содержательными абзацами вне таблицы. Действие: восстановить реальные колонки по изображению и сверить все пункты целиком. Приемка: каждый пункт остается связан со своим заголовком. Контроль: кандидат с вынесенным пунктом отклоняется; полная двухколоночная структура принимается после сверки; неопределенная связь получает pending.
2. Специальный шрифт может кодировать знак умножения в Private Use Area. Действие: читать форму по изображению, менять только подтвержденные вхождения, другие не исправлять автоматически. Контроль: нечитаемый код отклоняется; визуально подтвержденная точка принимается; неоднозначный символ сохраняется с пометкой.
3. OCR инфографики может смешать соседние колонки и потерять числа в кругах. Действие: отдельно читать смысловые зоны, связать показатель, единицу, значение и стрелку. Контроль: слитый OCR отклоняется; таблица связанных показателей принимается после визуального чтения; мелкий непрочитанный текст получает pending.
