## Структура управления устойчивым развитием

1. **Общее собрание акционеров АО «ИНК-Капитал»** — определение компетенций Совета директоров.
2. **Совет директоров АО «ИНК-Капитал»** — определение стратегии Группы компаний в области устойчивого развития.
3. **Комитет по устойчивому развитию, ESG и ИСМ**; **Комитет по аудиту** — подготовка рекомендаций для Совета директоров.
4. **Топ-менеджмент Группы компаний** — осуществление контроля за реализацией стратегии, распределение полномочий и ответственности между структурными подразделениями Группы компаний.
5. Центр устойчивого развития; Центр управления рисками и непрерывностью бизнеса; Комитет по развитию ИСМ; Комитет по рискам; Экологический комитет; Центральный комитет по производственной безопасности и охране здоровья — рассмотрение вопросов по направлениям, подготовка рекомендаций для Совета директоров / топ-менеджмента.
6. **Структурные подразделения Группы компаний, рабочие группы по отдельным вопросам** — генерация идей, предложений, реализация проектов.
7. **Благотворительный фонд Марины Седых** — реализация адресной помощи.
