# Повторяемые ошибки и контрольные сценарии

1. Декоративный год и логотип могут отсутствовать в текстовом слое. Признак: обложка с малым числом глифов. Действие: читать всю обложку по изображению, переносить видимые надписи и сохранять графику. Приёмка: дата и заголовок совпадают с оригиналом. Сценарий: отсутствующий год отклоняется; прочитанный по изображению принимается; нечитаемый остаётся pending.
2. Частный Unicode символа шрифта не является переносимой записью. Признак: U+E000–U+F8FF. Действие: сопоставить глиф с изображением и заменить стандартным символом без изменения позиций. Сценарий: квадратик вместо маркера отклоняется; подтверждённая галочка принимается; неизвестный знак сохраняется с пометкой.
3. Геометрическое объединение ячеек может смешать периоды и категории. Признак: несколько чисел и названий в одной ячейке при отдельных исходных колонках. Действие: по изображению восстановить строки и шапку, сверить каждое значение. Сценарий: слитые периоды отклоняются; отдельные сверенные колонки принимаются; непроверенная связь получает pending.
4. OCR может дублировать номер раздела, уже присутствующий в текстовом слое. Действие: сверить оригинал и удалить только подтверждённый дубль. Сценарий: лишний распознанный номер отклоняется; единственная верная запись принимается; неоднозначный повтор не удаляется автоматически.
5. OCR скана может терять скобки отрицательных сумм и заменять разделители. Действие: сверять все ячейки по изображению, сохранять исходные скобки и разделители, не проверять числа пересчётом. Сценарий: утраченная скобка отклоняется; визуально подтверждённая запись принимается; неразличимый знак отмечается pending.
