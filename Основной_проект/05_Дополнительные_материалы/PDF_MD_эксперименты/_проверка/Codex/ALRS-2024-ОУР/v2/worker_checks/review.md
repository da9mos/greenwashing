## Ограничения и дальнейшая проверка

Остальные 183 страницы имеют conversion_status=converted и review_status=pending. Для них не заявляется полная сверка по оригиналу. В report.md поставлены явные служебные пометки. Все страницы с таблицами, кроме 154, требуют сверки границ многострочных ячеек, строк, колонок, объединений, единиц и сносок. Возможен тот же дефект детектора, что исправлен на 154. Весь текст этих страниц сохранён механически, но правильность связей ещё не установлена. Мелкие растровые подписи, графики и нестандартные схемы на остальных страницах также требуют проверки. Печатные номера непроверенных страниц не выводились из смещения: они отмечены как не установленные.

Проверка целостности — validation.json. Локальная HTML-версия для контроля отображения — preview.html. Внешние ссылки извлечены из PDF, их доступность не проверялась. Полная проверка отображения всех 189 страниц не выполнена.

Локальный запуск Chrome для снимка HTML завершился ошибкой закрытия процесса браузера в доступной среде. Markdown разобран локальным markdown-it, HTML сохранён и проверен парсером, однако визуальный рендер сохранённой версии не подтверждён. Это ограничение относится в том числе к страницам со сверенным содержанием: checked обозначает здесь сверку содержания по исходным изображениям, а не приёмку отображения всей сборки.
