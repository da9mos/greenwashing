# **Подходы Компании к управлению рисками** **возникновения чрезвычайных ситуаций**

GRI 3-3


В рамках Общекорпоративной системы управления рисками в Компании
функционирует система управления рисками возникновения чрезвычайных ситуаций.



Для обеспечения мероприятий
по предупреждению и ликвидации
ЧС в каждом Обществе Группы созданы резервы финансовых и материальных ресурсов. Указанные



резервы предназначены для обеспечения аварийно-спасательных
и других неотложных работ, развертывания и содержания временных пунктов размещения и питания



работников и других первоочередных мероприятий по обеспечению устойчивого функционирования
объектов при возникновении ЧС.
