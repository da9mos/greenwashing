# Подтверждённые классы ошибок и контрольные сценарии

1. Заголовок смешанной страницы ошибочно принимается за всё содержимое. Признак: мало текста при наличии крупного растрового тела. Действие: осмотреть всю страницу, распознать тело OCR. Приёмка: все видимые абзацы представлены текстом; одна картинка не принимается. Кандидат с одним заголовком отклоняется, полный OCR принимается как converted, неясные символы остаются pending.
2. Обработка разворота единым потоком меняет порядок колонок. Действие: определить логические половины по вёрстке. Сквозную таблицу при этом не разрезать. Приёмка: последовательность абзацев и связи строк/колонок соответствуют источнику. Перемешанный кандидат отклоняется; проверенный порядок принимается; неоднозначный порядок получает пометку.
3. Вертикальные подписи схемы выпадают при текстовом извлечении. Действие: сравнить схему с изображением, отдельно перенести подписи. Приёмка: все подписи представлены; непрочитанные сохраняются как pending вместе с изображением.
4. Подавление графики отключает поиск таблиц, а включение графики способно подавить текст внутри цветных областей. Действие: извлекать полный текст независимо, таблицы восстанавливать по координатам и линиям отдельно. Приёмка: ни исходный текст, ни связи ячеек не теряются. Кандидат с пустой страницей отклоняется; структурированная таблица со сверенными ячейками принимается; машинный кандидат без сверки остаётся pending.
5. Поиск таблиц создаёт лишние столбцы на стыках коротких отрезков линий. Действие: сверить границы по шапке и геометрии; применять настоящие границы колонок или объединения HTML. Приёмка: отсутствуют придуманные заголовки ColN, все значения относятся к правильным полям. Фиктивные поля отклоняются, подтверждённая сетка принимается, неясная структура помечается pending.
