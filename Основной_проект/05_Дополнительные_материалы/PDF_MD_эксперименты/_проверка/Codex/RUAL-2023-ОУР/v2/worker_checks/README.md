## Контроль и ограничения

`validation.json`: 206 границ физических страниц ровно по порядку, 206 уникальных якорей, 206 существующих изображений, локальные ссылки разрешаются, U+FFFD и служебных строк TSV в основном документе нет. Сохранено локальное HTML-представление `report.preview.html`, широкие таблицы в нём имеют прокрутку.

Визуальная проверка отрисованного Markdown не завершена: локальный headless Chrome завершился с кодом 134 до создания снимка. Преобразование Markdown в HTML и разбор структуры выполнены; это не проверка отображения браузером.

Автоматический аудит финальной геометрии таблиц сохранён в `table_structure_audit.json`: на 46 страницах отмечены высокая доля пустых ячеек или неодинаковая логическая ширина строк. Это признаки для дальнейшего сопоставления с оригиналом, а не подтверждённые ошибки: реальные объединённые ячейки также могут вызывать такой сигнал. Все эти страницы остаются pending; их таблицы, соответствие чисел колонкам, сноски, порядок чтения и подписи графики полностью не сверены. На остальных pending-страницах также нужна полная сверка по исходному изображению. Пометки об этом стоят у каждой такой страницы в основном Markdown.

Общий документ не объявляется полностью проверенным. Актуальные раздельные статусы всех страниц и конкретные ограничения — `pages.json`; сводка — `review_summary.json`.
