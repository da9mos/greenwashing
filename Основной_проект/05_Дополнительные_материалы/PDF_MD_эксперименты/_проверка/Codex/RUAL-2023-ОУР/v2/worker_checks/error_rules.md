# Повторяемые классы ошибок

Правила относятся к проверке конвертации, не изменяют исходный документ или AGENT.md.

| Класс / причина | Признак | Действие по источнику | Условие приёмки / контрольный сценарий |
|---|---|---|---|
| Общая геометрическая таблица захватывает независимые текстовые колонки | Пустые фиктивные поля, разорванная связь названия и номера | Просмотреть страницу, выделить реальные колонки, перенести законченные пары | Кандидат со смешанными колонками отклоняется; правильные пары принимаются; неясная пара получает pending |
| Перекрывающиеся найденные ячейки | Один глиф имеет несколько владельцев, часть средней колонки вне таблицы | Проверить все сроки/категории и реальные объединения по изображению, восстановить ячейки | У каждого значения явный столбец; ошибочная привязка отклоняется, подтверждённая принимается, неразрешённая остаётся pending |
| OCR повторяет пригодный текстовый слой и считывает декорации | Нечитаемые короткие остатки около фото/логотипа | Сопоставить каждую OCR-область с изображением и native-текстом | Декоративный шум и повторы отклоняются; реальная растровая надпись сохраняется; неясное чтение отмечается |
| Служебный TSV попал в тело OCR | Строки с числовыми полями level/page/block/координаты/confidence | Отделить метаданные от текста, сверить реальную надпись по изображению | Метаданные отклоняются; собственно текст принимается только после сверки; отсутствие текста не заменяется координатами |
| В PDF есть повторные перекрывающиеся копии одного текста | Совпадающие смысловые абзацы в одной видимой карточке | Проверить количество видимых объектов, сохранить один только при подтверждённом наложении | Скрытый дубль отклоняется; два реально напечатанных абзаца сохраняются; без изображения удаление запрещено |
| Подписи диаграммы извлечены без отношений | Сначала числа, затем годы/серии | Сопоставить каждую подпись с рядом, периодом, единицей и легендой по изображению | Перемешанные значения отклоняются; подтверждённая таблица принимается; отсутствующий ряд не заполняется нулём |
| Правдоподобное исправление числа/разделителя вместо буквального переноса | Число или формат выделяется среди соседних | Увеличить область оригинала и сохранить напечатанное, даже если оно противоречит соседнему тексту | Автоматическая унификация отклоняется; буквальный источник принимается; неразборчивый знак помечается pending |
| Учёт символов ошибочно выдают за полную сверку | Все глифы учтены, но связи не проверены | Разделять conversion_status и review_status и указывать объём просмотра | Непросмотренная страница с checked отклоняется; converted/pending принимается; отсутствие оригинала фиксируется |
