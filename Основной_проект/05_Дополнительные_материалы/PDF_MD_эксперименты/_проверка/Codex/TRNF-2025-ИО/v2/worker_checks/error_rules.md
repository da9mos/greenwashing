# Подтверждённые классы ошибок и контрольные сценарии

## Межколоночный промежуток принимается за поле таблицы

Причина: линии/заливки соседних независимых таблиц имеют общие высоты. Признак: пустая вертикальная полоса и две независимые шапки, иногда заголовок одной таблицы попадает в другую. Действие: установить по изображению границы каждой таблицы, перенести исходные глифы по этим границам и проверить все строки/ячейки. Пустоту нельзя удалять лишь по отсутствию символов.

Контроль: кандидат с двумя независимыми шапками в одной таблице отклоняется; две таблицы с соответствующими ячейками принимаются; реальное пустое поле объяснений сохраняется; неоднозначный случай остаётся pending.

## Горизонтальная сортировка смешивает колонки

Причина: заголовок или колонтитул перекрывает естественный промежуток колонок. Признак: чередование строк из независимых абзацев/карточек. Действие: определить горизонтальные полосы и колонки по макету, переставить существующие объекты, сохранить глифы. Приёмка требует полного чтения затронутого блока; совпадение набора символов недостаточно.

Контроль: чередующиеся строки колонок отклоняются; последовательное чтение каждой подтверждённой колонки принимается; непроверенная многоуровневая схема получает pending.

## Дополнительный OCR создаёт дубли и строки технического формата

Причина: OCR поверх пригодного текстового слоя, фотографий или повреждённый разбор TSV. Признак: обрывки уже имеющихся слов, ложные значения, служебные числа координат/уверенности. Действие: сверить тело страницы по исходному изображению и текстовому слою, сохранить сырой OCR в протоколе, исключить подтверждённые артефакты. Если OCR содержит единственный текст тела, удалять его без визуальной транскрипции нельзя.

Контроль: дублированное предложение и строки TSV отклоняются; однократная подтверждённая транскрипция принимается; непрочитанный скан остаётся pending, даже при сохранённом изображении.

## Служебный Unicode попадает в основной текст

Причина: шрифтовое отображение интервалов/оформления на управляющий символ. Признак: U+0007 в начале списка/легенды. Действие: проверить участок изображения; удалить только при отсутствии содержательного знака. Для неизвестного символа не подставлять букву по правдоподобию.

Контроль: управляющий знак в читаемом тексте отклоняется; подтверждённый интервал без управляющего знака принимается; неизвестный буквенный глиф остаётся pending.

## Прямоугольник аннотации захватывает соседние строки

Причина: автоматическое извлечение подписи ссылки по прямоугольнику без проверки. Признак: подпись объединяет конец одной строки и начало следующей. Действие: сохранить назначение PDF, а в служебной навигации использовать техническую подпись физической целевой страницы; авторский текст перенести отдельно.

Контроль: искажённая подпись под видом авторского текста отклоняется; явная техническая подпись с существующим якорем принимается; неразрешённое назначение не угадывается.
