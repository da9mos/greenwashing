# Протокол переноса

Исходный PDF: ALRS-2023-ОУР.pdf, 170 физических страниц.
SHA-256: `734e3ec9ba1318460d06d3d1ec4d6a5a43dbbe89e255a584ed3a7ae916ad7a94`.

Начало работы: существующий механический кандидат с native_coverage.json. Ответы других моделей и старые транскрипции не использовались. Исходная версия сохранена в baseline/report.md и baseline/pages.json. Исходный PDF не изменен. Работа велась только в выделенном каталоге. Новые модели, API и дочерние агенты не запускались, файлы не скачивались.

## Охват

В report.md учтены все страницы 1–170, ровно по одному маркеру физической страницы, в исходном порядке. Все 170 исходных изображений сохранены в assets и совпадают с контрольными суммами входного реестра. Изображения служат визуальной опорой, основной текст перенесен отдельно.

Страницы 1, 7, 106, 143 и 144 прочитаны по исходным изображениям и исправлены. Проверка содержания и отношений таблиц на этих страницах отражена как review_status: checked. Это не означает проверки работы всех внешних адресов или проверки достоверности утверждений источника.

Остальные 165 страниц: conversion_status: converted, review_status: pending. Полная сверка этих страниц по оригиналу не выполнена. Их наличие в файле и учет исходных глифов не подтверждают правильность порядка чтения, всех строк таблиц и соответствия графических подписей числам.

Все 41 исходные диагностические записи прочитаны. Для 28 страниц с дополнительным OCR просмотрена общая исходная компоновка; шумные OCR-дубли удалены, нативное тело сохранено. Это частичная проверка, поэтому статус страницы не повышен. Строки со всеми диагностическими управляющими символами просмотрены как отдельные изображения из PDF, подтвержденные невидимые артефакты удалены. Исходные диагностические значения сохранены отдельно в полях *_original.

## Существенные исправления

- 1: обложка ранее содержала только OCR-прочерк; добавлены АЛРОСА, название отчета и 2023.
- 7: восстановлены переносы внутри названий строк, заголовок последней колонки, объединенная ячейка заинтересованных сторон и связи примечаний. Числовые строки взяты из кандидата без переписывания значений.
- 106: подписи графики ранее были разбиты на ложные строки и пустые ячейки. Собраны две таблицы: расходы по годам и направлениям. Все категории сопоставлены с видимыми числами; значения не пересчитаны.
- 143: в механическом кандидате отсутствовало тело трехлистного заключения. Выполнен Tesseract rus+eng по трем листам, затем текст исправлен визуальным чтением каждого листа. Сохранены сырые OCR-тексты, изображения листов и исправленная транскрипция в review/. Подпись присутствует в исходном изображении страницы.
- 144: восстановлены отдельная двухколоночная таблица заявления и GRI-таблица с объединениями. Исправлены ложные столбцы и оторванное слово «января»; неоднозначный пробел на границе ячеек разрешен по изображению.

Адресный журнал: corrections.json. Реестр всех страниц: pages.json. Механическая целостность итогового комплекта: final_integrity.json. native_coverage.json относится к baseline/report.md, а не к исправленной финальной версии.

## Отображение и ограничения

Сохраненный Markdown разобран локальным MarkdownIt с поддержкой HTML, создан preview.html. Все локальные ссылки проверены: отсутствующих вложений и внутренних якорей нет. HTML-таблицы содержат colspan/rowspan; просмотрщик должен поддерживать сырой HTML.

Визуальная проверка итогового HTML не завершена: локальный браузер не запустился в ограниченной среде (отсутствующая ожидаемая версия Playwright, затем отказ запуска установленного Chrome). Ничего не скачивалось. Для всех страниц display_review_status: pending. Сборка HTML сама по себе не считается визуальной проверкой отображения.

Непросмотренные целиком таблицы, колонки, диаграммы и графические надписи требуют дальнейшей сверки по странице-источнику. Комплект является рабочей версией, а не полностью выверенной транскрипцией.
