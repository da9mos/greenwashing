# Состояние конвертации

Рабочая версия полного документа, физические страницы 1–129. `../report.md` содержит текст каждой страницы и 129 сохранённых исходных разворотов. Изображения не подменяют текст. Предыдущего report.md в рабочем каталоге не было. Чужие каталоги не изменялись.

## Источник и обработка

Источник и SHA-256 записаны в source.json; контрольная сумма совпала с входным реестром. Все скопированные изображения проверены по SHA-256 входного реестра. Старые транскрипции и ответы других моделей не читались.

Первичный кандидат PyMuPDF4LLM сохранён в pages/. Итоговые фрагменты находятся в structured_pages/. В итоговой версии использованы текстовый слой PyMuPDF, рекурсивное разделение непересекающихся блоков по свободным промежуткам, таблицы по реальным горизонтальным границам и положениям исходных заголовков. Текст не пересказывался. Переносы строк внутри блоков объединены пробелами; дефисы не удалялись по догадке. Повторяющаяся навигационная полоса выше 42 pt исключена после осмотра исходных разворотов. Фактические печатные номера извлечены из верхней полосы, а не вычислены смещением.

При одном пробном вызове таблиц библиотека по умолчанию инициализировала локальный pymupdf-layout/ONNX. Этот кандидат отклонён: он склеивал слова и неверно разделял столбцы. Его вывод не использован в report.md. В дальнейших скриптах layout явно отключён (`use_layout(False)`). Внешние API не вызывались, загрузки не выполнялись, дочерние агенты не запускались.

На смешанной странице 123 тело трёх страниц аудиторского заключения доступно в текстовом слое. Дополнительно выполнен локальный Tesseract rus+eng; исходный рендер и OCR сохранены в audit-ocr.png и audit-ocr.txt. OCR служил альтернативным чтением, его ошибки в подписи не подставлялись вместо текстового слоя. Изображение подписи и печати сохранено в полном развороте.

Адреса и внутренние назначения PDF сохранены отдельными техническими блоками после каждой страницы. Внутренние переходы используют фактические целевые физические страницы из аннотаций. Доступность внешних сайтов не проверялась.

## Проверка и ограничения

Визуально сверены текст и логотип обложки (страница 1). Выборочно осмотрены оригинальные изображения страниц 2, 3, 4, 104, 121, 123 и 129; этот осмотр не считается полной сверкой страниц. Все остальные страницы имеют review_status=pending. Таблицы, объединённые ячейки, сноски, порядок сложных блоков и связи значений диаграмм остаются предметом полной сверки. Непроверенные значения диаграмм не оценивались по высоте столбцов. В HTML-представлении таблиц часть объединений развёрнута в пустые ячейки; оригинальная структура доступна на изображениях и требует проверки.

Построчный механический контроль подтвердил присутствие всех непустых строк текстового слоя основной области каждой страницы после нормализации пробелов и разметки. Он не устанавливает правильный порядок, привязку ячеек, точность символов и полноту текста внутри растровой графики.

Исправления: восстановлен порядок трёх колонок в обращении Председателя Правления; исключена ложная таблица на миниатюрах обложек в оглавлении; для приложений восстановлены табличные строки и столбцы по геометрии источника. Всего сохранено 53 HTML-таблицы. Полная проверка всех ячеек по оригиналу не заявляется.

Структурные проверки: 129 последовательных маркеров физических страниц, 129 записей реестра, все относительные файлы и внутренние якоря существуют, контрольные суммы 129 изображений совпадают. См. validation.json.

Создано локальное HTML-представление preview.html. Визуальное отображение не проверено: bundled Chromium отсутствует, попытка установленного Chrome завершилась SIGABRT в ограниченном окружении. Ничего не скачивалось. HTML поддерживает горизонтальную прокрутку таблиц, но это не проверено в запущенном просмотрщике.

Следующий этап: постранично сверить текст и все ячейки с изображениями, проверить подписи/легенды диаграмм и текст растровой графики, уточнить объединения таблиц и расположение сносок, затем проверить отображение в доступном просмотрщике. Реестр pages.json раздельно хранит conversion_status, review_status и issues каждой страницы.
