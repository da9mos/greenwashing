# Подтверждённые классы ошибок

1. Фоновая заливка как ячейка. Признак: ячейка занимает почти всю страницу и пересекается с обычной сеткой, много равноценных назначений глифов. Действие: по изображению выделить истинные тонкие правила и границы таблицы, повторить исходный перенос глифов. Приёмка: нет неоднозначных назначений; заголовки и значения визуально соответствуют своим колонкам. Сценарий: фон на всю страницу отклонить; сетку с верными связями принять; нерешённые границы оставить pending.

2. Служебные строки OCR как текст документа. Признак: табуляции, координаты, номера уровней и confidence попали в авторский текст. Действие: сохранить исходную диагностику, удалить служебные строки, восстановить тело из нативного слоя либо по изображению. Приёмка: в тексте нет TSV-полей, всё тело присутствует. Сценарий: TSV отклонить; визуально подтверждённый текст принять; неопознанные строки оставить pending.

3. Управляющие символы шрифтовой карты. Признак: неотображаемые символы Cc внутри фраз или на концах строк. Действие: сверить их место на изображении, убрать лишь при отсутствии печатного знака. Приёмка: слова, пунктуация и промежутки сохранены. Сценарий: автоматическую замену неизвестным символом отклонить; подтверждённый невидимый артефакт убрать; видимый неопознанный знак оставить pending.

4. OCR карточек разрушает связь с номерами. Признак: многоколоночные карточки читаются по колонкам, номера теряются, соседние описания смешиваются. Действие: визуально прочитать карточки, зафиксировать отдельные номер, объект, описание. Приёмка: каждый исходный номер связан с единственным верным объектом и полным описанием. Сценарий: смешанные карточки отклонить; полную сверенную таблицу принять; нечитаемую карточку оставить pending с изображением.
