# Правила подтверждённых классов ошибок

## TSV как текст OCR

Причина: CSV-парсер интерпретирует кавычку внутри распознанного слова как начало многострочного поля. Признак: в тексте появляются числовые колонки координат и confidence, разделённые табуляцией. Действие: разбирать TSV без семантики CSV-кавычек, проверять число полей каждой строки; не публиковать технические колонки. Дубликаты текстового слоя подавлять после проверки координат. Приёмка: в авторском тексте нет строк TSV, настоящий растровый текст перенесён отдельно.

Контрольный сценарий: поле с одиночной кавычкой и следующей строкой координат отклоняется; корректное слово принимается; слово с неясным чтением остаётся pending.

## Потеря структуры таблицы при полном учёте глифов

Причина: слабые или растровые линии сетки не распознаны. Признак: несколько самостоятельных полей оказываются в одной ячейке, необъяснимые rowspan или строки тела выходят из таблицы. Действие: установить границы по оригиналу, повторно назначить исходные глифы с учётом объединений, проверить соседние строки. Приёмка: связи строки/колонки восстановлены по источнику, а не только сохранён набор символов.

Контрольный сценарий: слитые заголовки и показатели отклоняются; отдельные правильные ячейки принимаются; неопределённое объединение получает pending.

## Ложная надстрочность обычной строки

Причина: флаг PDF-интерпретатора не гарантирует фактическую надстрочную позицию относительно основного текста. Признак: целое предложение после маркера списка обёрнуто в sup. Действие: сравнить размер и базовую линию с изображением, снять только подтверждённый ложный флаг. Приёмка: обычный текст имеет обычную позицию, реальные сноски и степени сохранены.

Контрольный сценарий: целая обычная строка в sup отклоняется; подтверждённая цифра сноски принимается; неоднозначный короткий знак остаётся pending.
