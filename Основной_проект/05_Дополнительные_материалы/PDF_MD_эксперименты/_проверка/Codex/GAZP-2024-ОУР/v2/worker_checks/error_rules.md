# Повторяемые классы ошибок

Правила применяются к похожим источникам; контрольные сценарии ниже проверяют логику правил, а не истинность конкретной транскрипции.

| Класс | Причина и признак | Действие по источнику | Условие приёмки / контрольный сценарий |
| --- | --- | --- | --- |
| Пропуск текста на плашке | Извлекатель принимает цветную подложку за графическое препятствие; текстовый блок исходного слоя не найден в результате | Сопоставить исходные блоки и изображение, изменить обработку фона, сверить весь блок | Кандидат без тела плашки отклоняется; весь читаемый блок принимается после сверки; нечитабельные символы остаются pending |
| Цифры в частной области Unicode | Ошибочная таблица соответствий шрифта; присутствуют PUA вместо десятичных знаков | Установить соответствие по видимым глифам исходника и применить только к подтверждённому шрифту/набору | Неподтверждённая подстановка отклоняется; подтверждённая принимается; неизвестный глиф получает пометку |
| Смешанная страница с непрочитанным телом | Распознан только колонтитул, а основной лист встроен изображением | Проверить весь растр, применить доступный OCR, прочитать ключевые и неуверенные участки, сохранить подписи отдельно | Один заголовок плюс картинка не принимается как транскрипция; извлечённое тело получает converted, полностью сверенное — checked |
| Жёсткая нижняя граница | Проза продолжается ниже типовой линии страницы | Сравнить все блоки вне границы с исходником; расширять область для содержательных строк | Обрезанная последняя строка отклоняется; весь подтверждённый блок принимается; неустановленная роль строки отмечается |
| Разрыв связей строк и чисел | Линейное извлечение читает столбцы отдельно | Восстановить сетку по координатам или сохранить моноширинную раскладку и оригинал; отдельно проверять шапку и сноски | Список названий отдельно от списка значений отклоняется; подтверждённая сетка принимается; неоднозначные связи не получают checked |
| Потеря декоративного текста | Надпись переведена в контуры или включена в изображение | Читать изображение; не принимать ошибочный OCR по сходству | Неполный заголовок отклоняется; визуально прочитанный принимается; неясное слово остаётся с пометкой |
| Ошибка кодировки именованного назначения | UTF-8 отображён как Latin-1; аннотация не содержит разрешённой страницы | Проверить декодированный ключ по словарю назначений PDF | Угаданная по печатному номеру страница отклоняется; точное совпадение имени принимается; неизвестное имя остаётся неразрешённым |
| Смешение OCR-колонок реквизитов | Строки соседних организаций склеиваются | Прочитать колонки по изображению и восстановить независимые блоки; не угадывать номера под печатью | Перемешанные адреса отклоняются; каждый блок с подтверждёнными значениями принимается; закрытое печатью поле отмечается |
