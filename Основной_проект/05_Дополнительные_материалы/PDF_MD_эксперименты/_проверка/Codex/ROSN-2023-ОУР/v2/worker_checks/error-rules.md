# Повторяемые дефекты и контрольные сценарии

## Перестановка полос разворота
Причина: горизонтальные зоны двух самостоятельных полос перекрываются по высоте, и алгоритм извлечения выбирает неверный порядок. Признак: продолжение абзаца с правой полосы появляется раньше начала с левой. Действие: установить границы полос по изображению, извлечь каждую отдельно, восстановить последовательность; проверить колонки и переходы. Приёмка: последовательность всего блока подтверждена оригиналом.
Сценарий: кандидат «продолжение — начало» отклоняется; подтверждённое «начало — продолжение» принимается; неоднозначный порядок остаётся pending с изображением.

## Заголовок скрывает сканированное тело
Причина: наличие текстового слоя только в шапке ошибочно трактуется как наличие полного текста. Признак: большой растр с текстом при коротком извлечении. Действие: проверить всю основную область, применить локальный OCR к телу, сохранить изображение, отдельно проверить реквизиты и порядок колонок. Приёмка: всё тело распознано, существенные ошибки устранены по оригиналу.
Сценарий: заголовок плюс картинка без текста тела отклоняется; полная сверенная транскрипция принимается; непроверенный OCR получает converted/pending.

## Ложные столбцы автоматической таблицы
Причина: детектор принимает декоративные линии или границы текстовых блоков за границы ячеек. Признак: описание разрезано между полями, периоды слиты в одну ячейку, одна строка продублирована. Действие: отклонить кандидат; по координатам источника восстановить поля либо сохранить читаемую моноширинную матрицу вместе с изображением; проверить шапку, строки и примечания. Приёмка: у каждого значения установлены категория и период по оригиналу.
Сценарий: разрезанное описание с фиктивным Col2 отклоняется; подтверждённая исходником матрица принимается; непроверенная матрица остаётся converted/pending.
