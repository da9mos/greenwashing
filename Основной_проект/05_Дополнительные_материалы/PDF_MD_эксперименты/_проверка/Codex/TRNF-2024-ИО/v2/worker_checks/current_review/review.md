## Отображение и целостность

Все 303 маркера физических страниц идут по порядку ровно один раз. Существование всех локальных ссылок и якорей проверено; все 303 исходных изображения совпадают по SHA-256 с входным реестром. После исправлений не осталось U+FFFD или символов частной области Unicode. Итоговые проверки — integrity.json.

Создан локальный HTML-рендер полного Markdown. Chrome недоступен для headless запуска: установленный браузер завершился SIGABRT; ничего не скачивалось. Альтернативно PyMuPDF Story отрендерил текст/таблицы 28 выбранных страниц без переполнения; картинки исходника исключены только из этих служебных предпросмотров. Визуально просмотрены рендеры 31, 42, 53, 70, 144, 194. Остальные созданные предпросмотры не названы просмотренными. Проверка отображения всего документа не завершена.

## Ограничения

Рабочая версия, не полностью выверенная транскрипция. Для 294 страниц требуется полная содержательная сверка. На непросмотренных страницах могут сохраняться дефекты порядка строк, слияния колонок и связей сносок, не выявляемые учетом символов. Служебные исходные изображения доступны для каждой страницы; они не заменяют перенесенный текст. Числовая точность остальных таблиц не заявляется подтвержденной визуально.
