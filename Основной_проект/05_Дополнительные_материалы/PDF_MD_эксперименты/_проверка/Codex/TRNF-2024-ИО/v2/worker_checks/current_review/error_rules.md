# Повторяемые классы ошибок

1. Невидимая/неполная рамка таблицы может породить пустые фиктивные колонки и склеенные числовые поля. Признаки: разное число занятых позиций по строкам, множество пустот, два числа в одной ячейке. Действие: сверить видимую геометрию, адресно разделить глифы по исходным координатам, проверить шапку и все строки. Приемка: каждое поле связано со своим заголовком; пустоты исходника сохранены.
2. Текст схем с несколькими независимыми колонками может извлекаться вперемежку при полном учете символов. Признак: обрывки предложений перемежаются заголовками других колонок. Действие: восстановить блоки по картинке, сохранить отношения через явные столбцы/списки. Приемка: каждый пункт целиком под своим заголовком.
3. Частный код шрифта не равен видимому знаку. Признак: Co/U+FFFD. Действие: сверить изображение и контекст единиц/отметок, заменить только подтвержденный знак. Приемка: значение и смысл соответствуют изображению.
4. OCR инфографики смешивает числа, подписи, исторические врезки. Признак: числа без категории, единицы или года. Действие: прочитать исходную схему и явно связать данные; не оценивать по высоте столбца. Неясный участок оставить pending с изображением.

Контрольные сценарии: кандидат «год A: два числа; год B: пусто» при двух исходных колонках отклоняется; кандидат с числами в соответствующих колонках принимается после сверки. Исходно пустая ячейка не заполняется. Схема с перемешанными строками отклоняется, восстановленные смысловые блоки принимаются после сверки. Неоднозначное соответствие без достаточного оригинала получает pending. Эти сценарии проверяют правило, а не заменяют сверку конкретного PDF.
