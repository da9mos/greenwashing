# Состояние рабочей версии

Учтены и перенесены все 167 физических страниц, в исходном порядке. Исходный PDF не изменялся. За основу взят предоставленный механический кандидат с native_coverage.json; другие транскрипции, модели, API и загрузки не использовались.

## Объём проверки

- Полностью прочитаны по изображениям обложка и разделители: 1, 4, 7, 13, 16, 35, 43, 53, 83, 122. Только эти 10 страниц имеют review_status=checked.
- Содержание страницы 2 и таблицы/карта страницы 9 рассмотрены по полным изображениям и исправлены адресно. Вся страница, включая ссылки и отображение, не объявляется checked.
- На каждой странице с диагностикой Unicode просмотрен исходный фрагмент для каждого встречающегося класса проблемного символа. Это проверка класса шрифта на странице, а не всех его вхождений и не всей страницы. Координаты сохранены в review/unicode_locations.json; просмотренные фрагменты — unicode_0–3.jpg.
- Все диагностические записи разобраны в diagnostic_review.json; рассмотрение диагностики не означает устранения всех проблем или проверки всех ячеек.
- Для 29, 56, 82 просмотрена общая структура и удалён добавленный OCR-шум; текстовый слой тела сохранён. Сверка всего тела не закончена.
- Для 141–146 просмотрена структура разворотов, OCR тела повторён отдельно по сторонам без порога уверенности. На 141 дополнительно прочитан правый скан и исправлены отдельные очевидные ошибки единиц и реквизитов. Полная пословная сверка этих приложений не закончена. Текст OCR присутствует в report.md, изображения его не заменяют.
- 123 просмотрена по изображению для проблемного назначения ссылки. Весь массив таблиц GRI не объявляется проверенным.
- Остальные страницы не прошли полную визуальную сверку. Всего 157 страниц остаются review_status=pending при conversion_status=converted.

## Исправления

Добавлены пропущенные на обложке название, год и подпись. Удалены OCR-дубли на разделителях. В содержании восстановлены строки «название — печатный номер». На 9 восстановлены пять строк приоритетов, их метрики и общая финансовая цель, сопоставлены обозначения карты и активы, восстановлены три строки результатов. Знаки двух символьных шрифтов переведены в Unicode, невидимый управляющий код удалён. Полный журнал — corrections.json. Исходная версия сохранена как report.native.md, исходный реестр — pages.native.json.

## Ограничения

Это рабочая полная конвертация, не полностью проверенная транскрипция. Порядок чтения сложных страниц, связи сносок, вложенные/объединённые ячейки и числа сканированных приложений требуют дальнейшей адресной сверки. Полный учёт исходных глифов относится к исходному механическому кандидату и не доказывает правильность конечных связей или OCR.

Внутренние назначения части ссылок исходного PDF некорректны/неоднозначны. Они не заменены догадками по печатному номеру. Служебный список ссылок воспроизводит исходные назначения; наличие якоря не удостоверяет содержательную правильность назначения.

Markdown преобразован в локальный HTML; таблицы и ссылки разобраны парсером. Все относительные вложения и якоря существуют. В CSS предпросмотра широкие таблицы прокручиваются. Браузерная визуальная проверка заблокирована средой: Chromium завершается с ошибкой MachPortRendezvousServer / Permission denied (1100). Фактическое отображение всего документа не проверено. Подробности — render_validation.json.

## Файлы контроля

- pages.json — все страницы, раздельные conversion_status, review_status, issues, тип содержимого, извлечённые обозначения в колонтитулах, сведения о внесённых правках.
- validation.json — контроль порядка страниц, ссылок, контрольных сумм и кодов Unicode; не оценка точности.
- native_coverage.baseline.json — исходное свидетельство механического учёта глифов; native_coverage.json явно ограничивает область его применения.
- report.preview.html — производный HTML для локального просмотра.
- review/ — исходные фрагменты, необработанный повторный OCR, сценарии воспроизведения адресных правок.
