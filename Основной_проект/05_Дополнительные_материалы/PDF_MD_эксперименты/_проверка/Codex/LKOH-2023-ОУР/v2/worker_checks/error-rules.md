# Повторяемые дефекты и контрольные сценарии

## Исключение текста вместе с графикой
Причина: конвертер считает цветную или векторную область иллюстрацией и исключает расположенный внутри неё текст. Признак: текстовый слой насыщен, а Markdown содержит только колонтитулы либо существенно меньше слов. Действие: сверить область по изображению, повторить извлечение без исключения графических областей. Условие приёмки: основной текст и числовые подписи присутствуют, связь с категориями сохранена.
Контрольный сценарий: кандидат с одной картинкой и колонтитулами отклоняется; кандидат с прочитанным телом принимается после сверки; неустановленные подписи остаются pending.

## Смешение колонок разворота
Причина: общий алгоритм порядка чтения объединяет строки разных логических страниц. Признак: заголовки и строки соседних страниц чередуются. Действие: установить границы по изображению, извлечь логические страницы отдельно. Условие приёмки: левая логическая страница предшествует правой, поля таблиц не смешаны.
Контрольный сценарий: чередующийся кандидат отклоняется; установленный по оригиналу порядок принимается; неясная граница требует изображения и статуса pending.

## Текстовый заголовок над растровым телом
Причина: наличие заголовка в текстовом слое ошибочно принимается за наличие всего текста. Признак: изображение содержит абзацы, отсутствующие в извлечении. Действие: OCR всего тела с подходящими языками, затем визуальная вычитка. Условие приёмки: все абзацы прочитаны и сверены.
Контрольный сценарий: заголовок с картинкой отклоняется; OCR без сверки получает converted/pending; свёрстанный и полностью сверенный текст принимается как checked.
