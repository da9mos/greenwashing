# Протокол конвертации

Источник и SHA-256 записаны в pages.json; исходный PDF не изменялся. Использованы только исходный PDF, механический реестр/изображения и локальные библиотеки. Старые транскрипции, внешние API и дочерние агенты не использовались. Итоговый конвейер PyMuPDF4LLM работал в legacy-режиме с отключённым layout-модулем.

Обработаны физические страницы 1–115. Обложка — отдельная страница, остальные страницы — развороты; деление на левую и правую части установлено обзором изображений. Печатные номера извлечены из расположенных у внешних краёв нижних колонтитулов, без вычисления смещения. Текст каждого блока сохранён в pages/. Состояние каждой страницы — в pages.json.

Основной текст извлечён из текстового слоя. После обнаружения пропуска текста в цветных графических областях отключено исключение векторной графики из текстовой обработки. Развороты повторно извлечены по половинам для предотвращения чередования текстов левой и правой страниц. Плотные таблицы и матрицы перенесены позиционным текстом Poppler в блоках `text`: пробелы сохраняют соответствие заголовков и значений; это не полностью нормализованные Markdown-таблицы. Колонтитулы сохранены, чтобы не удалять содержательные фрагменты по эвристике.

Растровый текст заключения на странице 114 и в левой половине страницы 115 обработан локальным Tesseract с языками rus+eng. Оригинальные OCR-выходы сохранены. Словесный логотип исправлен по изображению; прочие возможные ошибки OCR не устранены полностью и отмечены в report.md. Подпись, печать, схемы и графика сохранены на оригинальных изображениях всех страниц в assets/.

Обложка просмотрена целиком по изображению, её текст сверен. Обзорные контактные листы всех страниц использованы только для определения вёрстки; это не полная сверка содержания. Страницы 2–115 имеют conversion_status=converted и review_status=pending. Нельзя считать таблицы и OCR прошедшими полную проверку.

Проверки целостности: 115 последовательных маркеров физических страниц; 115 записей реестра; все 115 изображений существуют; непустая транскрипция каждой страницы. Внутренних переходов, извлечённых как LINK_GOTO, не обнаружено; существующие внешние аннотации сохранены отдельными техническими перечнями. Доступность внешних сайтов не проверялась.

Markdown локально преобразован в HTML (rendered.html). Запуск Chrome для визуального просмотра завершился SIGABRT: визуальное отображение HTML не проверено. Проверка структуры и наличия вложений выполнена программно; она не подтверждает точность содержания.

Ограничения и следующая работа: визуально сверить все страницы 2–115, порядок колонок, привязку примечаний, все ячейки таблиц и текст OCR; затем при необходимости нормализовать позиционные таблицы. Сохранённые исходные изображения позволяют проводить такую сверку без исходного каталога. Итог — рабочая версия всего документа.
