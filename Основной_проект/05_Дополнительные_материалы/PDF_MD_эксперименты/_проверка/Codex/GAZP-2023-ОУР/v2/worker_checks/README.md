# Протокол конвертации

Обработаны физические страницы 1–136. Извлечён текстовый слой; для сканов на физических страницах 132–133 применён локальный Tesseract rus+eng, затем исправлены отдельные ошибки по изображениям. Новые модели, API, дочерние агенты и скачивания не использовались. Предыдущие транскрипции не читались.

Все страницы имеют conversion_status: converted. Полностью визуально сверена обложка (страница 1). Остальные 135 страниц имеют review_status: pending. Миниатюры всех страниц просмотрены для изучения вёрстки; этот обзор не считается полной сверкой. На странице 12 визуально проверены три таблицы и исправлен порядок связанных текстовых блоков; на страницах 132–133 проверены и исправлены отдельные OCR-объекты. Ни эти проверки, ни диагностика охвата не подтверждают точность всего документа.

В report.md сохранены текст, таблицы и координатное текстовое представление сложных таблиц/инфографики. Полные исходные изображения сохранены как визуальная опора, включая подписи, печати и графику. Автоматически исключённые блоки цветных плашек восстановлены альтернативным извлечением; цельные развороты не разрезаны по центру. Подробности исправлений: corrections.json; нерешённые места: issues у каждой страницы в pages.json.

Проверены 136 последовательных маркеров физических страниц, 136 записей реестра, 136 вложений и их SHA-256 по входному реестру, существование внутренних якорей и локальных ссылок. Все исходные горизонтальные текстовые слова диагностически сопоставлены с результатом; оставшиеся несовпадения преимущественно вызваны выделением надстрочных сносок. Это не посимвольная сверка и не оценка точности. Повторные навигационные обозначения не воспроизводились как основной текст.

Markdown разобран в HTML (preview.html). Визуальная проверка отображения не выполнена: запуск локального браузера запрещён sandbox (MachPortRendezvousServer Permission denied). Установка браузеров и сетевые действия не выполнялись. В HTML предусмотрена прокрутка широких таблиц и координатных блоков, но её работа визуально не подтверждена.

Для завершения проверки необходимо по каждому pending-блоку сверить текст и сноски, все ячейки таблиц и соответствия диаграмм оригиналу, затем проверить отображение. OCR заключения требует полной посимвольной сверки; мелкий текст печатей не считается проверенным. Рабочая версия не выдаётся за полностью сверенную транскрипцию.
