# Повторяемые ошибки и контрольные сценарии

## Непечатаемый символ в текстовом слое

Причина: PDF-шрифт сопоставляет служебный глиф управляющему символу Unicode. Признак: категория Cc вне пробельных символов. Действие: просмотреть положение в PDF, определить, есть ли видимый знак, сохранить исходную версию и только затем удалить невидимый артефакт. Условие приёмки: видимый текст и его разделители не изменены; управляющий символ исчез. Нельзя механически удалять все управляющие знаки по совпадению кода без сверки.

Сценарий: кандидат с невидимым звонком внутри текста отклоняется; тот же текст с подтверждённым отсутствием печатного знака принимается; неизвестный видимый глиф остаётся pending с изображением.

## Знаки специального шрифта

Причина: галочка или маркер списка извлекается как Private Use Area. Признак: символ Co. Действие: прочитать глиф по PDF и заменить установленным видимым эквивалентом, сохраняя число знаков и связи с объектом. Условие приёмки: эквивалент видим в конечном отображении и соответствует исходнику.

Сценарий: квадрат вместо галочки отклоняется; сверенная галочка принимается; неразобранный знак не заменяется предположением.

## Ложная геометрия таблицы

Причина: детектор принимает декоративные линии и рамки за общую сетку, объединяет самостоятельные таблицы, оставляет инициалы за границей ячейки. Признаки: отдельные буквы рядом с таблицей, множество пустых ячеек, смешанные заголовки, неправдоподобные colspan/rowspan. Действие: восстановить реальные границы по изображению, перенести исходные глифы в установленную ячейку, проверить каждую строку и общие ячейки. Условие приёмки: все значения связаны со своими заголовками и периодами, совпадают первая/последняя строки, нет потерянных букв.

Сценарий: таблица с верным набором символов, но смешанными строками отклоняется; таблица с проверенными ячейками принимается; неустановленная принадлежность значения получает pending.

## OCR поверх пригодного текстового слоя

Причина: большая фотография запускает OCR всей страницы, распознаватель повторяет тело с искажениями. Признаки: фрагментарный дополнительный OCR, совпадающий по месту с уже извлечённым текстом. Действие: установить роли изображения и полного текста, удалять лишь подтверждённые дубли/шум. На настоящих сканах читать всё тело отдельно по логическим страницам. Условие приёмки: нет потерь уникального текста изображения.

Сценарий: один снимок вместо текста скана отклоняется; полный OCR тела с явными нерешёнными местами сохраняется converted/pending; полностью сверенное тело может стать checked.
