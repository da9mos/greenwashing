# Правила для повторяемых дефектов

## Фоновая сетка распознана как таблица данных

Причина: векторные линии декоративного фона попадают в детектор. Признак: обрезанные названия элементов, огромные пустые ячейки и смешение навигации с содержимым. Действие: установить по изображению роль фона, восстановить основные надписи отдельно, сохранить фон изображением. Приемка: нет ложных отношений между декоративными глифами и содержательными полями.

Контрольный сценарий: кандидат с химическими символами в ячейках оглавления отклоняется; оглавление с подтвержденными названиями и изображением фона принимается; неустановленная роль сетки остается pending.

## OCR продублировал существующий текстовый слой

Причина: OCR всего растра смешанной страницы повторно распознает уже извлеченный текст и элементы рисунка. Признак: OCR-конфликты по тем же координатам, повторные знаки пунктуации, плюс вместо маркера списка. Действие: проверить изображение, удалить только подтвержденный дубль; самостоятельный растровый текст прочитать отдельно. Приемка: ни повторов, ни потерянного растрового тела.

Контрольный сценарий: два варианта одного числа рядом отклоняются; единственное подтвержденное число принимается; конфликт без читаемого источника остается pending с изображением.

## Перенос строки ячейки превращен в новую строку таблицы

Причина: сетка детектора включает ложные границы либо не соответствует линиям оригинала. Признак: части одного показателя лежат в отдельных строках, появляются лишние пустые столбцы. Действие: восстановить настоящие границы и объединения по исходным линейкам и расположению глифов, сохранить числа без пересчета. Приемка: каждое продолжение относится к исходной ячейке, инвентарь глифов совпадает, вся затронутая таблица просмотрена.

Контрольный сценарий: два несвязанных фрагмента одного заголовка отклоняются; единая исходная ячейка принимается; неустановленная граница остается pending. Совпадение глифов само по себе не дает checked.

## Управляющий символ из карты шрифта

Причина: нестандартная карта шрифта порождает непечатный код. Признак: управляющий символ в середине видимого заголовка. Действие: сверить соответствующее место по изображению; не заменять по правдоподобию. Приемка: сохранен видимый знак либо удален код, которому не соответствует видимый знак.

Контрольный сценарий: непечатный код как часть слова отклоняется; подтвержденная видимая строка принимается; неразличимый символ остается pending с фрагментом источника.
