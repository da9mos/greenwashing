# Подтвержденные классы ошибок

1. Наложенные или скрытые текстовые слои. Признак: несколько несовместимых заголовков в одной области. Действие: читать видимое изображение, сохранять исходный кандидат отдельно. Приемка: видимый текст один раз, без невидимого варианта. Сценарий: два варианта — отклонить; один подтвержденный изображением — принять; неразличимый — pending.
2. Маркеры с поврежденным Unicode. Признак: U+FFFD перед пунктом. Заменять только после просмотра формы знака. Сценарий: догадка по контексту — отклонить; видимая точка — принять как •; неоднозначный знак — pending.
3. Ложные надстрочные числа диаграмм. Причина: близкие подписи разных секторов приняты за степень. Проверить положение и цвет сектора по оригиналу. Сценарий: соседнее число в sup — отклонить; отдельные подтвержденные подписи — принять; неподтвержденная категория — пометка, pending.
4. Геометрические псевдоколонки и перемешанные строки. Признак: множество пустых ячеек или чередование продолжений двух колонок. Восстановить логические поля и порядок по изображению; проверить всю затронутую таблицу. Сценарий: фиктивные поля — отклонить; все исходные ячейки с подтвержденными заголовками — принять; неясное объединение — pending.
5. Повторный OCR поверх пригодного текста. Признак: бессвязный повтор слов в конце страницы. Проверять наличие исходного текста в основном переносе и на изображении, удаленное сохранять в журнале. Сценарий: удаление без источника — отклонить; подтвержденный дубль — принять; потенциально новый текст — pending.
