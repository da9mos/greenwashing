# Правила повторяемых ошибок

## Служебная разметка OCR в авторском тексте
Причина: некорректный разбор табличного вывода OCR и распознавание декоративных элементов. Признак: строки с несколькими целочисленными полями координат и confidence, обрывки уже имеющихся слов, ложные знаки на иллюстрациях. Действие: сравнить изображение с текстовым слоем, удалить только подтверждённые повторы и метаданные; отсутствующий текст тела распознать отдельно. Приёмка: все видимые содержательные блоки имеют текст, служебные поля отсутствуют.
Контроль: TSV-строка отклоняется; подтверждённое слово тела принимается; неясная подпись остаётся pending с изображением.

## Шрифтовые управляющие символы
Причина: нестандартное соответствие кодов шрифта печатным знакам. Признак: Cc/Co/U+FFFD. Действие: сверить знак по изображению; BEL без печатного знака удалить, видимый маркер списка отобразить стандартным символом. Приёмка: сохранены видимые символы и положение знаков; неизвестные не заменяются догадками.
Контроль: невидимый BEL отклоняется; подтверждённый маркер принимается; неразличимый символ помечается.

## Геометрическая ячейка объединяет смысловые столбцы
Причина: отсутствие вертикальных линеек, хотя текст выровнен в самостоятельные поля. Признак: разные периоды, номера страниц и комментарии внутри одной ячейки; несколько чисел без явных категорий. Действие: установить границы по исходным заголовкам и геометрии, перенести исходные глифы без переписывания чисел, сохранить объединённые строки и пустоты. Приёмка: каждая ячейка однозначно связана с заголовком, периодом и строкой после сверки всего объекта.
Контроль: четыре значения в одной ячейке без периодов отклоняются; четыре исходных значения под проверенными заголовками принимаются; неоднозначные границы получают pending.
