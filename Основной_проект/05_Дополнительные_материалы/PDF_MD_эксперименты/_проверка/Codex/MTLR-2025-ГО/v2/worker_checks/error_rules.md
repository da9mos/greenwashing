# Повторяемые классы ошибок

1. Соседние таблицы склеиваются общим детектором. Признак: повторная нумерация столбцов и перемешанные номера принципов в одной строке. Действие: установить независимые области по оригиналу, восстановить границы строк и колонок из исходной геометрии. Приёмка: каждая нумерованная запись имеет собственные поля, объединённые шапки не разрезаны. Сценарий: склеенные половины отклонить; независимые согласованные таблицы принять; неоднозначные поля пометить pending.

2. Текстовые объекты отметок не совпадают с видимостью. Признак: все варианты извлечены как X, хотя на изображении выбран один. Действие: сверить растровое отображение каждой группы, учесть невидимые/маскированные объекты. Приёмка: выбранный вариант и пустые поля совпадают с оригиналом. Сценарий: три выбранных варианта при одном видимом кресте отклонить; совпавшую группу принять; нечитабельную оставить pending.

3. OCR дополняет хороший текст ложными остатками. Признак: обрывки и псевдослова, повторяющие строки или контуры иллюстрации. Действие: проверить соответствующий оригинал, сохранить содержательные подписи, удалить только подтверждённые артефакты. Сценарий: бессмысленный остаток отклонить; подтверждённую подпись принять; сомнительный фрагмент сохранить с пометкой.

4. Заголовок из другой колонки прерывает предложение. Признак: заголовок оказывается между частями перенесённого слова. Действие: сверить положение заголовка и порядок колонок; вынести заголовок к началу соответствующего раздела. Сценарий: разорванное заголовком слово отклонить; восстановленный порядок принять; неясный порядок оставить pending.
