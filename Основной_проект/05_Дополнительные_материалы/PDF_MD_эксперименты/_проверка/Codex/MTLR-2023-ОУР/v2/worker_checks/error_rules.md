# Подтверждённые классы ошибок

1. **Графический шрифт как текст.** Причина: кодирование диаграммы буквенно-цифровыми последовательностями. Признак: шрифт Chartwell и последовательности с `=` или `+`. Действие: сверить видимое изображение, сохранить подписи и рисунок, вынести коды из авторского текста в журнал. Приёмка: читаемые значения не удалены. Сценарий: `100=` из графического шрифта отклоняется как текст; обычное число из текстового шрифта сохраняется; неизвестный шрифт получает pending.

2. **Пустая таблица с графическими отметками.** Причина: ✓ нарисован векторно и отсутствует среди глифов. Признак: пустые ячейки в извлечении при видимых отметках. Действие: перенести состояния по каждой строке и колонке изображения. Приёмка: каждая отметка и пустота сверены отдельно. Сценарий: пустое извлечение при видимой отметке отклоняется; подтверждённая отметка принимается; нечитаемая ячейка получает pending.

3. **Потеря последнего периода.** Причина: детектор не распознал внешний край сетки. Признак: значения периода остаются вне таблицы, хотя на изображении находятся в её правой колонке. Действие: явно задать проверенную по оригиналу сетку и повторить общий механический перенос глифов. Приёмка: все периоды и строки сопоставлены изображению. Сценарий: вынесенные значения последнего года отклоняются; полный столбец с исходными глифами принимается; неопределённая граница получает pending.

4. **Схема ошибочно распознана как таблица.** Причина: прямоугольники и линии диаграммы образуют ложную сетку. Признак: множество неоднозначных ячеек и соединение независимых блоков. Действие: отклонить ложную сетку, повторить общий перенос без табличного детектора для этого объекта, сохранить оригинал и явно отметить неподтверждённые связи. Приёмка: исходный текст не потерян; схема не объявлена структурно проверенной без сверки всех связей.

5. **OCR-служебные данные в тексте.** Причина: технический TSV ошибочно попал в читаемый слой. Признак: строки уровней, координат и confidence. Действие: сохранить исходный OCR в проверочном архиве, исключить технические строки из авторского текста после подтверждения наличия текстового слоя. Приёмка: тело документа остаётся извлечённым, технические координаты отсутствуют. Для настоящего скана требуется повторный корректный OCR; удаление служебных данных не заменяет чтение тела.
