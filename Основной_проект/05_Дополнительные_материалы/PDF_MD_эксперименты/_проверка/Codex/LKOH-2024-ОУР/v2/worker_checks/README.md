# Протокол конвертации

Источник указан в pages.json, SHA-256 сверяется с предоставленным реестром. Исходник не менялся. Чужие каталоги и старые транскрипции не использованы.

Обработаны физические страницы 1–116. report.md содержит постраничный текст, 173 геометрически восстановленные HTML-таблицы, назначения доступных аннотаций PDF и полные исходные изображения страниц. Изображения в assets побайтово совпадают с реестром входов. Текст не заменён изображениями.

Выполнен обзор общей вёрстки всех страниц по контактным листам. Более подробно просмотрены изображения страниц 6, 31, 91, 114 и скан заключения на странице 115. Сканированный текст заключения на странице 115 обработан локальным Tesseract, исправлены URL, ФИО под печатью и ложные символы логотипа; этот фрагмент сверен по изображению. Это не полная сверка физических страниц. Все страницы имеют conversion_status=converted и review_status=pending.

При пробном извлечении pymupdf4llm выявлены потеря основного текста и искажения ячеек; этот кандидат отклонён. Итог построен прямым извлечением нативных символов PyMuPDF и векторных границ. Исправлены таблицы, определённые только по шапке, разрезание объединённых заголовков, захват примечания таблицей и неверное чтение пиктограммы ссылки как цифры. Опорные промежуточные версии сохранены отдельно.

Ограничения: все ячейки таблиц не сверены; порядок блоков на сложных разворотах, соответствие подписей графиков значениям, переносы слов и связи сносок требуют дальнейшей проверки. Неоднозначные участки явно обозначены техническими пометками в report.md. Нет утверждения о полной точности документа.

validation.json содержит технические проверки: последовательность всех 116 маркеров страниц, учёт страниц в реестре, контрольные суммы изображений, существование вложений и внутренних якорей, баланс HTML-тегов. Дополнительно проверено сохранение количества букв и цифровых символов нативного тела каждой страницы, кроме страницы с добавленным OCR; это контроль потерь, а не доказательство порядка или правильности ячеек.

Markdown преобразован локально в rendered.html. Визуальный просмотр результата в headless Chrome не состоялся: браузер завершился при запуске в ограниченной среде. Отображение итогового Markdown не проверено. Широкие таблицы обёрнуты в контейнеры с горизонтальной прокруткой, поддержка зависит от просмотрщика.

Для воспроизведения: convert.py, затем finalize.py, затем validate.py. Не запускайте finalize.py дважды без convert.py: он добавляет проверенный OCR-фрагмент к новой механической конвертации. Никакие загрузки и внешние API не требуются.
