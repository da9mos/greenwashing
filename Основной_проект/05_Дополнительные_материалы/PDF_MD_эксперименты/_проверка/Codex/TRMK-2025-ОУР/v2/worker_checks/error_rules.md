# Правила для повторной проверки

## Независимые таблицы разворота

Причина: детектор продолжает горизонтальные линии через широкий пустой корешок. Признак: одна сетка пересекает корешок, содержит пустые колонки между независимыми шапками, а строки слева и справа имеют разные границы. Действие: установить по изображению границы самостоятельных таблиц, перестроить каждую по исходным линиям; повторить учет глифов и сверку всех ячеек. Приемка: независимые таблицы читаются последовательно, число и принадлежность столбцов подтверждены оригиналом.

Контрольный сценарий: кандидат с общей строкой двух самостоятельных шапок отклоняется; независимые сетки с подтвержденными полями принимаются; неоднозначная граница получает pending. Посимвольный охват не является критерием семантической приемки.

## Нестандартные глифы

Причина: управляющий символ или Private Use Area в PDF-шрифте. Признак: категории Cc/Co в исходном тексте. Действие: получить изображение каждой строки, определить видимость и роль символа. Невидимый знак удалить только после просмотра; графический маркер передать видимым символом с исходным цветом либо изображением. Приемка: просмотрены все вхождения, текст и легенда не теряют своих связей.

Контрольный сценарий: молчаливое удаление Co отклоняется; подтвержденный цветной маркер принимается; нечитаемый глиф сохраняется с изображением и pending.
