# Повторяемые ошибки и контрольные сценарии

## Отсутствующая Unicode-карта CID-шрифта

Причина: код глифа интерпретируется как Unicode. Признак: греческие/управляющие символы в русском тексте при визуально нормальном PDF. Действие: вывести атлас непосредственно из встроенного шрифта, установить карту отдельно для каждого подмножества, применить только к производной копии. Условие приемки: сверенные глифы, читаемые строки и отсутствие управляющих символов; словарная правдоподобность сама по себе недостаточна.

Контроль: кандидат с буквальным CID вместо кириллицы отклоняется; кандидат с проверенной картой конкретного шрифта принимается для этапа конвертации; непроверенный глиф получает пометку pending. Одинаковое название семейства не разрешает переносить карту между разными подмножествами.

## Полосатая таблица и декоративная рамка

Причина: детектор воспринимает залитые полосы как отдельные таблицы, а навигационную рамку — как набор пустых ячеек. Признак: чередование таблиц и одиночных абзацев со значениями, обломки слов в столбцах, пустые строки у колонтитула. Действие: установить настоящие границы по изображению, перенести целую таблицу по геометрии глифов и проверить всю шапку и каждую строку. Условие приемки: одна связная таблица с полным набором строк и правильными заголовками.

Контроль: кандидат с вынесенными из таблицы значениями отклоняется; восстановленная проверенная сетка принимается; неустановленная принадлежность ячейки остается pending.

## Показатели в общей строке и ошибочный superscript

Причина: PDF объединяет соседние карточки в один блок и помечает крупное значение как надстрочный текст относительно мелкой подписи. Признак: значение одной карточки стоит внутри подписи другой. Действие: восстановить каждую карточку по изображению, сохранив точные цифры и единицы. Условие приемки: каждому значению соответствует своя подпись; настоящие сноски сохранены.

Контроль: перемешанная строка отклоняется; подтвержденная пара «подпись — значение» принимается; неоднозначный знак сохраняется с пометкой и изображением.

## Разделение колонок внутри слова

Причина: выбранная граница пересекает длинную строку соседней колонки. Признак: короткие окончания слов оказываются после целой колонки. Действие: проверить распределение символов каждого исходного слова по областям; изменить границу только после просмотра страницы. Условие приемки: слово не делится между независимыми областями, порядок колонок соответствует вёрстке.

Контроль: разделенное слово отклоняется; целая строка в правильной колонке принимается; пересекающий несколько колонок объект требует отдельной области.
