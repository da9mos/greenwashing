# Подтвержденные классы ошибок и контрольные сценарии

## Перемешивание колонок

Причина: сортировка блоков только по вертикальному положению объединяет соседние колонки. Признак: продолжение фразы появляется после чужого абзаца. Действие: установить границы горизонтальных секций и колонок по изображению, восстановить порядок целых блоков. Приемка: полностью прочитать затронутую секцию и ее продолжения по оригиналу.

Контроль: кандидат с чередованием строк соседних колонок отклоняется; кандидат с подтвержденным порядком колонок принимается; неясное межколоночное продолжение получает `pending`.

## Ложная таблица внутри блок-схемы

Причина: линии графического оформления принимаются за границы ячеек. Признак: слова разрезаны между соседними столбцами, таблицы перекрываются. Действие: исключить перекрывающиеся таблицы, сохранить изображение схемы и пространственное текстовое представление, отдельно проверить подписи и стрелки. Приемка: нет искусственного дробления слов и потери связей; иначе `pending`.

Контроль: кандидат с частями одного слова в разных фиктивных ячейках отклоняется; схема с проверенными подписями и связями принимается; пространственный текст без полной проверки стрелок остается `pending`.

## OCR по декоративной обложке и сканированному приложению

Причина: декоративная графика порождает мусор, а native-заголовок не означает наличия текстового слоя тела. Признак: короткое текстовое извлечение при видимом плотном тексте либо бессмысленные фрагменты среди изображений. Действие: распознать всю основную область локальным OCR, затем прочитать ее по изображению; графическую подпись сохранить изображением. Приемка: весь текст тела прочитан, числа и реквизиты сверены.

Контроль: вариант с одним заголовком и картинкой вместо текста отклоняется; полное проверенное чтение принимается; непрочитанная область получает `pending`.
