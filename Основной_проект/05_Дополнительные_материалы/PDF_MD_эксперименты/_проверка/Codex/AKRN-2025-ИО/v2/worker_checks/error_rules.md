# Правила для повторяемых дефектов

1. Дополнительный OCR поверх пригодного текстового слоя может дублировать строки и распознавать декор. Проверять каждую добавленную строку по изображению; удалять только подтверждённые дубли/артефакты. Сценарий: дубль отклонить, отсутствующий в текстовом слое видимый текст принять, неясную строку оставить pending.
2. Управляющие коды в извлечении не следует заменять по догадке. Сопоставить их позиции с изображением и удалить только при отсутствии видимого текстового знака. Сценарий: невидимый код удалить, видимый знак сохранить/перенести, неясный знак отметить.
3. Полный символьный охват не исключает перемешивания колонок. Устанавливать полосы чтения по вёрстке, сохранять инвентарь строк при перестановке. Сценарий: чередование независимых колонок отклонить, последовательное чтение принять, пересекающиеся блоки отметить.
4. Сетка детектора может объединять независимые таблицы и заполнять промежутки пустыми ячейками. Сравнить границы с оригиналом и повторно извлечь исходной программой; принять только с сохранением символов и проверкой структуры. Пустота сама по себе не доказывает лишний столбец. Неразрешённые заголовки оставить pending.
