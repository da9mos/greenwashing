# Повторяемые классы ошибок

1. OCR поверх пригодного текстового слоя может добавлять ошибочные дубли. Признак: короткий бессвязный OCR-блок при полном нативном тексте. Действие: сравнить со всем изображением и текстовым слоем; удалять только подтверждённый дубль. Приёмка: уникальный текст сохранён, декоративный знак не превращён в слово.
2. Детектор таблиц может объединить независимые половины разворота. Признаки: десятки пустых столбцов, строки параллельных таблиц в одной строке. Действие: установить границы по изображению, разделить объекты, перенести исходные глифы по областям. Приёмка: каждая строка имеет правильные смысловые поля; сравнение символов не заменяет проверку связей.
3. Отсутствующая горизонтальная граница правой ячейки означает возможное объединение строк. Действие: сохранить rowspan по оригиналу, не приписывать подпись одной строке по её вертикальному центру. Приёмка: ссылка/значение относится ко всем исходным строкам объединения.
4. Геометрическое определение надстрочных знаков может ошибочно поднять текст пункта списка. Действие: проверить размер и базовую линию по изображению; снять верхний индекс только в подтверждённом блоке.

Контрольные сценарии: OCR-«слово» без печатного аналога отклоняется, уникальная печатная подпись принимается; таблица с перемешанными половинами отклоняется, раздельные таблицы с совпадающими полями принимаются; неясная граница или подпись получает pending с изображением. Эти сценарии не являются сверкой страниц.
