# Подтверждённые классы ошибок конвертации

## Ложная таблица поверх инфографики
Причина: геометрические рамки и декоративные линии интерпретируются как сетка; конвертер исключает область из основного текста, но не выдаёт её содержание.
Признак: резкое падение длины Markdown относительно текстового слоя; пропавшие абзацы и значения.
Действие: отклонить кандидата, сохранить текст независимо от таблиц; сетку восстанавливать по источнику отдельно.
Приёмка: все содержательные блоки присутствуют; каждой числовой ячейке соответствует исходный столбец. Счётчик символов служит диагностикой, а не доказательством точности.
Контрольный сценарий: пустой кандидат при непустом источнике отклоняется; кандидат с сохранённым текстом и проверенной сеткой принимается; неясные объединения получают pending.

## Неверный порядок вложенных страниц
Причина: внутренний порядок объектов PDF отличается от визуального порядка нескольких вложенных документов.
Признак: заключительная часть предшествует введению.
Действие: определить границы вложенных страниц по изображению, читать их слева направо, внутри каждой сверху вниз.
Приёмка: начало, продолжение и окончание идут в последовательности оригинала; текст тела не заменяется изображением.
Контрольный сценарий: обратный порядок отклоняется; визуально подтверждённый порядок принимается; неопределённые границы получают pending.

## Пропуск повёрнутых подписей
Причина: извлечение с реконструкцией колонок может исключать текст с нестандартным направлением.
Признак: подписи есть в текстовых блоках PDF, но отсутствуют в Markdown.
Действие: сохранить точную подпись из источника, определить её объект по изображению; до определения явно отделить техническую пометку.
Приёмка: подпись и её связь с графическим объектом проверены; при непроверенной связи статус остаётся pending.
Контрольный сценарий: кандидат без подписи отклоняется; проверенная подпись принимается; положение по догадке не принимается.
