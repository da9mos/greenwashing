# Контур ESG

Рабочая платформа для сверки Markdown, извлечения заявлений и внешнего поиска по отчётам. В интерфейсе можно выбрать компанию и документы, увидеть состояние этапа, открыть исходники и выгрузить CSV. Скоринг компаний в эту версию не входит.

## Сервер и данные

- HTTPS: https://187-124-165-215.nip.io/sber-esg/. Доступ по логину и паролю. Реквизиты лежат в локальном файле «Доступ к платформе ESG.txt».
- Приложение на `srv` в `/opt/sber-esg-review`, сервис `sber-esg-review.service`. Nginx проксирует выделенный путь в localhost. Данные и очередь в `/var/lib/sber-esg-review/review.sqlite`.
- Корпус — отдельная копия 92 Markdown-отчётов. Аудит проверяет SHA-256 и порядок физических страниц для всех файлов. Числа, графики, таблицы и полнота извлечения требуют содержательной сверки.
- Классификация использует профиль v3.1 из рабочего пакета проекта. Повторный прогон использует локальные ответы, прошедшие валидацию, и текущий хеш источника и промпта.

## Исполнение

`worker.py` читает очередь через SSH под существующей авторизацией и выполняет запуск Codex локально. На сервере клиент Codex не авторизован. Очередь и результаты сохраняются при перезапуске. Для фоновой работы на Mac зарегистрирован LaunchAgent `tech.synapt.sber-esg-worker`. Он обрабатывает по одной партии за цикл и автоматически возвращает частично готовый отчёт в очередь. После закрытия технического извлечения по отчёту создаётся очередь внешнего поиска по заявлениям. Пакеты, не прошедшие проверку, остаются открытыми для разбора.

Внешний поиск доступен для одного заявления и всех известных заявлений выбранного отчёта. Веб-ответ проходит проверку контракта и содержит источники и пояснение. Категоричная отметка требует отдельной сверки с оригиналом PDF. Результаты из пилота и новые проверки хранятся раздельно.

Для паузы создайте файл `~/.local/state/sber-esg-worker/PAUSED`. Уже запущенная партия закончит работу. Чтобы продолжить, уберите файл. Прогресс сохраняется при недоступности Mac или временном сбое входа в Codex. Сам интерфейс работает на сервере независимо от Mac.

## Проверка

Техническая сверка на сервере прошла для 92 Markdown и 14 731 страницы. Проверены HTTPS и вход, переключение компаний и отчётов, фильтрация, выборочный вызов сверки, исходник Markdown, CSV, раскрытие записи и постановка внешнего поиска в очередь. Интерфейс проверен в Chrome на 1440 и 390 пикселях.

Контрольный фактчекинг проверен сохранением результата по НДТ Газпрома. Источники Росстандарта и записи регулятора добавлены с оговорками о периметре и доступе. Автоматический веб-запуск первой строки вернул ответ, отклонённый валидатором, и не присвоил вердикт. Принятый результат получен прямым веб-поиском с последующей валидацией по тому же контракту.
