# Автономный PDF → Markdown: без внешнего конвертера

[Инструкция агента](PDF_TO_MD_AGENT.md) · [Независимая проверка](INDEPENDENT_QA.md) · [Протокол проверок](verification.json)

Эта версия полностью локальная. PDF не отправлялись на внешние сервисы, API не вызывались, ключи не использовались. PyMuPDF4LLM обрабатывает геометрию и таблицы, Tesseract rus+eng распознаёт изображения. Сетевые соединения Python в конвертере запрещены. Установленные библиотеки и языковые данные используются локально; установка зависимостей до работы может требовать интернета.

## Что изменено

- Двухстраничные развороты распознаются по геометрии и обрабатываются слева направо. При отсутствии центрального промежутка разрез не выполняется автоматически.
- Сохраняются два локальных кандидата: для структуры и для порядка чтения. Один вариант не объявляется универсально правильным.
- OCR учитывает все изображения страницы и малый объём буквенного текста: заголовок над большим сканом больше не исключает распознавание. В первом прогоне 132/133 пропускались, после изменения правила оба заключения распознаны локально.
- Сложная таблица соц115 восстановлена в 6 колонок по оригинальным координатам и строкам, с отдельными 2022/2023 и изменениями. Контрольные значения 0,102; 0,323; 1,963 сохранены. Это адресная правка для данного PDF, а не универсальные координаты для любых таблиц.
- Для соц57 и130 сохранены локальные таблицы, а порядок абзацев исправлен по координатам текстовых колонок исходного PDF. Все непросмотренные блоки остаются pending.

## Как работает агент

Сначала создаёт машинные MD всех страниц, raw_text, координаты и кандидаты таблиц. Затем сам открывает изображения спорных страниц, выбирает локальный вариант по блокам, исправляет таблицы/порядок чтения по оригиналу и записывает основание. При отсутствии возможностей прочитать изображение оставляет конкретное место непроверенным. Для этого не нужны регистрация, API-ключ или кредиты конвертера.

Точный запуск и схемы — в PDF_TO_MD_AGENT.md. В tools находятся переносимый конвертер, рендер страницы и зависимости. Скрипт — первая стадия; агентская сверка оригинала — вторая. Инструкция не обучает веса модели и не гарантирует одинаковую точность любой модели.

## Границы качества

Полный машинный прогон завершён. Полная посимвольная приёмка всех 220 страниц не выполнена. OCR может ошибаться в идентификаторах, названиях и цифрах. Простое деление разворота не решает все внутренние колонки; сложные таблицы требуют проверки границ. Диаграммы, повторы значений, сноски и неразборчивые участки отмечены в page_review.csv. Автоматические таблицы в tables — кандидаты, а не подтверждённые факты.

Сохранены исходные PDF вне пакета; хеши и имена содержатся в manifest.json каждого документа. Это конвертация отчётности, не фактчекинг заявлений компании.
