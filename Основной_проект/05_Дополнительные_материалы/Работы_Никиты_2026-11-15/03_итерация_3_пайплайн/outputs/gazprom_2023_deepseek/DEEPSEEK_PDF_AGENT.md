# DeepSeek: проверенный профиль сравнения PDF → Markdown

Это отдельно разрешённый пользователем вызов DeepSeek API. Базовый локальный конвертер не начинает отправлять документы наружу автоматически. Здесь изображения публичных PDF передаются модели deepseek-flash; внешние конвертеры не используются.

Ключ берётся только из macOS Keychain клиентом 05_Инструменты/15_DeepSeek_API/deepseek_client.py. В промпты, логи и пакет он не попадает. Для повторения используйте локальные исходники и своё разрешённое API-подключение.

## Как выполнен опыт

1. Сохранены неизменяемые копии ранее полученных локальных MD и их хеши
2. Из исходных PDF сформированы изображения страниц; развороты — отдельные левое и правое изображения
3. Модель не получала локальный MD как подсказку: переносила содержание исходных изображений независимо
4. Сохранены точный операционный промпт system_v1.txt, хеши изображений, полные содержательные ответы и usage
5. Выполнено посимвольное сравнение обеих транскрипций; все протоколы проверены обратной сборкой результата
6. Конкретные ошибки проверены по оригиналам и независимыми агентами. Отбракованные повторные ответы сохранены
7. Рабочий набор выбран через selection.json. Отсутствующая запись означает v1; наличие v2 само по себе не означает его приёмку

## Обязательные правила модели и вызывающего кода

- Использовать модель с поддержкой изображений, не отправлять их в модель без vision
- Переносить всю страницу, не краткое содержание; не терять первую/последнюю строки, годы, единицы, легенды и ограничения аудиторских заключений
- Проверять сноски названия строки и значения раздельно. После правки — контроль всех соседних строк
- Для каждого значения диаграммы сохранять явные год и серию. Не заполнять непредставленные значения
- Проверять JSON, наличие Markdown, номер страницы и finish_reason=stop. Сохранять сырой ответ до json.loads
- Невалидный JSON не означает плохое распознавание, но такой ответ нельзя молча принять. После форматных ошибок использовать отдельно протоколированный Markdown-ответ без угадывания текста
- Не принимать problems=[] как проверку качества. Проверять исходное изображение и регрессионные случаи отдельно
- Сохранять v1, v2 и адресные source-checked исправления раздельно. Кандидат с регрессией не становится выбранным
- Не менять локальный эталон после сравнения, чтобы искусственно повысить совпадение
- Не называть посимвольное совпадение точностью. В локальном результате тоже обнаружены слабые места

Полная расширенная инструкция — PDF_TO_MD_AGENT_UPDATED.md. Операционный промпт в этом опыте короче полной инструкции, его точный текст сохранён для воспроизводимости. Этот опыт не является обучением весов модели.
