# Газпром 2023: полное сравнение PDF → Markdown

[Инструкция агента](PDF_TO_MD_AGENT.md) · [Независимая проверка](INDEPENDENT_QA.md) · [Постраничное сравнение](page_comparison.csv) · [Исправления](corrections.csv)

## Объём и порядок

Полностью обработаны оба PDF Газпрома за 2023 год, представленные в проектном корпусе: отчёт о социальной деятельности (136 страниц) и экологический отчёт (84 страницы). Всего 220 PDF-страниц. Это не утверждение о наличии всех возможных публикаций Газпрома за год.

Сначала выполнены оба локальных прохода PyMuPDF4LLM 2.1. Результаты и хеши зафиксированы. Только затем созданы два полных задания LlamaParse Agentic. Предыдущий пилот четырёх страниц существовал до этого опыта; полного облачного результата до локального прохода не было. Локальный проход выполнен библиотекой под управлением агента, а не ручной перепечаткой220 страниц.

Результаты содержат все страницы без пропусков и дублей маркеров. `local_pages` сохраняет raw_text и геометрию шрифтов; `cloud/result.json` — полный ответ сервиса, `cloud/tables.json` — табличные элементы с ячейками и координатами. Необработанные результаты не перезаписаны. Коррекции в рабочем MD применены скриптом по проверенным оригиналам; они не являются литературным редактированием источника.

Сопоставлены все220 страниц: наличие, номера, объём, числовые токены и число строк таблиц. 92 сигнала — очередь для проверки, не92 доказанные ошибки. Например, на сканах локально почти пусто, а сервис распознаёт текст. Сравнение токенов не измеряет точность: сырой текст и оба конвертера могут ошибаться одинаково; различаются сноски, колонтитулы и формат чисел.

Визуально и семантически адресно проверены ключевые блоки на9 страницах: социальные57,115,130,132,133 и экологические13,24,40,76. Это не полная посимвольная сверка220 страниц. Полный машинный проход завершён, полная ручная приёмка каждой ячейки — нет. Рабочие MD имеют статус review_pending для непроверенных мест.

Внесено 13 адресных записей исправлений. Журнал содержит основания. FAR1,963 — правильное число; предыдущий ошибочный вывод агента про сноску исправлен ещё в пилоте. Нельзя «улучшать» данные на основании догадки о шрифте.

## Вывод для обработки

Для этого корпуса сервис лучше восстанавливает сложную вёрстку и сканы. При этом он не сохраняет абсолютно точно все подписи, периметры и структуру таблиц. Надёжный процесс: независимый локальный проход → облачный проход → постраничное сравнение → сверка спорных блоков с PDF → журнал исправлений → рабочий MD. Выбор делается по блоку; правило «сервис всегда прав» непригодно.

Извлечение заявлений и фактчекинг не выполнялись в рамках этого опыта: конвертация и проверка истинности разделены. В частности, таблица экологических целей уже была в локальном тексте раньше, но не попала в реестр заявлений; замена конвертера сама по себе этот этап не исправляет.

## Стоимость, доступ и воспроизводимость

Два задания выполнены в Agentic. Базовая оценка по 10 кредитов/страницу — 2200 кредитов без учёта возможного кэша. Фактическое списание и остаток баланса API не предоставил. Покупки кредитов и изменения автооплаты не выполнялись. Ключ использован только в памяти процесса; он отсутствует в сохранённых файлах.

Инструменты находятся в tools. Локальный переносимый скрипт повторно прогнан на84 страницах экологического отчёта; его страницы совпадают с первым локальным результатом. Облачный переносимый скрипт подготовлен по реально выполненному запросу; отдельный повтор платного задания ради теста не создавался. При возобновлении он использует сохранённый ID.

```bash
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements.txt
.venv/bin/python tools/local_convert.py input.pdf output
.venv/bin/python tools/cloud_convert.py input.pdf output --tier agentic
.venv/bin/python tools/compare_report.py output
```
