# Семантические ограничения builder: адресный QA

15.11.2026. Прочитаны `src/build_review_v2.py`, фактические `llm/nikita_dynamics/v2/review_A.json` (19проверок) и `review_B.json` (25). Изменения исходника выполняет root; этот аудит меняет только тесты и данную записку.

## Найдено на реальных данных

1. **Потеря нуля:** `T-CHMF-003`, наблюдение2025: `reported_value=0`, `value=null`. Выражение через `or` экспортировало пустую строку вместо0. Проверка должна различать0 и None/отсутствие.
2. **Происхождение сборки:** входной `data/out/metrics_dynamics.csv`, реестр `reports.csv` и фактически прочитанные fallbackстраницы `data/pages/*.jsonl` не входили в `inputs_sha256`. Одних хэшей LLMответов недостаточно для воспроизводимости.
3. **Разные годы — корректный случай:** `T-PHOR-002` имеет assessment_year2025 и measurement_year2024. Нельзя переносить результат измерения в2025. Тест подтверждает отдельное хранение годов и запись в `value_2024`.

В текущих44проверках конфликтующие сопоставимые значения одного года и неизвестные target_id не обнаружены. Их отсутствие не заменяет входную валидацию.

## Риски, воспроизведённые на изолированном корпусе

| Риск | Контракт |
|---|---|
| Два разных сопоставимых значения одного года | Ошибка, вместо молчаливого «последнее победило»; одинаковое значение с двумя цитатами допустимо |
| Неизвестный target_id | Ошибка, вместо незаметного пропуска проверки |
| NaN/Infinity/bool/нечисловая строка в сравниваемом value | Ошибка: в годовой ряд допускается конечное числовое значение |
| comparison_valid строкой/числом | Ошибка: явное поле должно быть boolean, а не неявно отвергнуто/приведено |
| Повторное применение к уже проверенной строке | Исходный `old_status` сохраняется |
| Старый validation_errors.json после успешной пересборки | Удалить устаревшую ошибку; актуальный passed-маркер и старые ошибки не должны конфликтовать |
| Несовпадающая цитата | Ошибка до публикации CSV, прежний passed-маркер отзывается |

`tests/test_review_v3.py` содержит11тестов с изолированными временными CSV/JSONL. Рабочие данные ими не изменяются. Первый запуск до исправлений:3метода прошли,8не прошли (18ошибок с учётом параметризованных подслучаев). Эти результаты относятся к исходнику до исправлений; итоговый прогон будет записан ниже.

Технические проверки не доказывают семантическую эквивалентность показателей, достоверность PDF или двойную человеческую разметку.
