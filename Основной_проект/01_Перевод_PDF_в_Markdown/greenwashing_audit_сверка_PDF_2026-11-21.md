# Сверка PDF и Markdown

Основание работы — [этап 1 из задания Никиты](https://t.me/c/5235656038/454836). Исходный снимок репозитория — `c5ec4426bd7e9a5c0ec740f92c37c8a40c929f84`.

## Результат прогона

Обновлены **92 отчёта на 14 731 физических страницах**. Открыты и обработаны 92 PDF. Проверены последовательность маркеров, видимость якорей после полного рендеринга и внутренние ссылки. Все 43 теста прошли.

Выполнено 10 адресных исправлений. По геометрии PDF объединено 256 122 пар строк. Машинный журнал пометил 2 234 страницы для дополнительной сверки.

Для РУСАЛа за 2023 год использована копия, опубликованная АК&М. Скачивание файла из реестра обрывалось. SHA-256 копии отличается. Соответствие текстового слоя и порядка страниц проверено сравнением с прежним Markdown на всех 206 физических страницах. Исходная ссылка в реестре сохранена. [Копия отчёта на АК&М](https://www.akm.ru/upload/akmrating/RUSAL-sustainability-report_2023.pdf).

## Повторная проверка вёрстки

После первого прогона выборочно просмотрено по одной отрисованной странице каждого из 92 отчётов. Найденные ошибки использованы для повторных прогонов. Проверка научилась восстанавливать сетку по координатам PDF, соединять перенесённые подписи и возвращать выпавшие ячейки, если их можно однозначно прочитать. На рендере обнаружились лишние пустые столбцы в таблицах с годами. Для них добавлено отдельное правило и проверка на сохранность заполненных ячеек.

В итоговом комплекте на 167 страницах изменилось содержимое. Агент автоматически исправил 183 таблицы на 159 страницах. По оригиналам внесено 17 адресных исправлений на семи страницах. Для всех 159 страниц с автоматическими табличными правками дополнительно сверено сохранение слов, цифр и знаков в отображаемом тексте. Прошли все 49 тестов.

## Сверка входа для анализа заявлений 22 ноября

В [отчёте НОВАТЭКа за 2023 год](../00_Отчёты/НОВАТЭК/NVTK-2023-ОУР.md#pdf-page-105) исправлены 11 таблиц на физических страницах 105–107 (печатные развороты 208–213). Из PDF восстановлены годы, группы, единицы измерения и заголовки показателей. Ячейки с объединённым текстом в таблицах найма, состава руководства и минимальных окладов разнесены по столбцам. Четыре пояснения к сноскам сохранены. По координатам PDF со строками и столбцами Markdown сопоставлены 894 заполненные числовые ячейки и прочерки.

Полный прогон открыл исходные PDF всех 92 отчётов и проверил 14 731 физическую страницу. Изменились только страницы 105–107 одного отчёта. Остальные 91 Markdown совпали побайтно. Все 67 тестов прошли с доступными PDF. Следующий прогон НОВАТЭКа подтвердил побайтную воспроизводимость правок.

Штатный `prepare_corpus.py` агента анализа заявлений собрал 3 716 пакетов по 92 отчётам. В целевых блоках НОВАТЭКа проверены связи 13 значений с заголовками во всех 11 исправленных таблицах и наличие четырёх пояснений к сноскам на странице 107. Например, в строке «До 30» из первой таблицы два столбца за 2021 год явно связывают женщин с 430 человек и 11%. Проверка охватила подготовку входа. Оценка ответов модели и полная ручная сверка корпуса остаются открытыми.

## Что требует ручного чтения

Автоматическая сверка выявляет страницы с повреждёнными символами, слабым текстовым слоем или расхождениями в словах и написании чисел. Она может пометить числовое значение при изменении формата записи или порядке чтения. Диаграммы, сложные таблицы, OCR и смысловые связи за пределами выборки остаются предметом проверки по изображению PDF.
