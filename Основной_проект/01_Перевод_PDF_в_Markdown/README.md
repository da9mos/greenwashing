# Перевод PDF в Markdown

Откройте [инструкцию агента](Агент/PDF_TO_MD_AGENT.md). На входе оригинал PDF, на выходе читаемый Markdown с физическими номерами страниц, таблицами, числами и примечаниями. Используйте OCR при слабом текстовом слое и сверяйте спорные числа и графику с оригинальной страницей.

[Формат журнала сверки](Агент/Справка/README.md). Локальный скрипт `Агент/review_gate.py` проверяет привязку сохранённых доказательств к PDF и MD. Для его запуска нужен PyMuPDF. Готовые переводы лежат в [реестре отчётов](../00_Отчёты/Реестр_отчётов.csv).
