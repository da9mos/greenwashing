# Итоги проверки

[Сводка прогона по 92 отчётам](Сводка_прогона.csv).

Формат выдачи: один XLSX на компанию, один лист и один CSV на каждый отчёт. Шесть полей: номер, заявление, тип, E/S/G, проверка и пояснение. Исходная страница и ссылки на внешние материалы указываются в пояснении. Цвет только в шапке.

[Пилот Газпрома](Газпром/Газпром_2023_ESG_пилот.xlsx) содержит 719 строк. Внешний поиск ранее проведён по четырём заявлениям, по остальным 715 он открыт. Итоговые книги публикуются по мере прохождения приёмки.
