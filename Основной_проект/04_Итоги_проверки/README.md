# Итоги проверки

[Актуальная сводка фонового прогона](../06_Прогон_корпуса/Сводка_прогона.csv) · [принцип обработки и состояние очереди](../06_Прогон_корпуса/README.md). В папке каждой компании добавлена `Сводка_компании.md`; она учитывает повторно проверенные ответы локального worker. Прежний реестр ниже относится к ранее опубликованному пилоту и не является текущим счётчиком фоновой обработки.

[Сводка прогона по 92 отчётам](Сводка_прогона.csv).

Формат выдачи: один XLSX на компанию, один лист и один CSV на каждый год отчётности. Два отчёта одного года объединяются на одном листе, нумерация продолжается. Шесть полей: №, Заявление, Тип заявления, E/S/G, Проверка, Причина (источник). Последнее поле содержит обоснование, страницу PDF и ссылки на внешние материалы. Цвет только в шапке.

[Пилот Газпрома](../../Старая_версия/Локальный_пилот_Газпрома/Газпром_2023_ESG_пилот.xlsx) содержит 719 строк. Внешний поиск ранее проведён по четырём заявлениям, по остальным 715 он открыт. Итоговые книги публикуются по мере прохождения приёмки.

Новый прогон: [Газпром](Газпром/README.md), 4 партии, 282 кандидатных заявления, 4 листа и 4 CSV.

Сборка книги: выполните `python3 prepare_company_export.py GAZP путь_к_выгрузкам company.json`, затем `node build_company_excel.mjs company.json папка_результата` с доступным `@oai/artifact-tool`. Первый скрипт связывает выгрузки фактчекинга с реестром компании, второй экспортирует и повторно читает XLSX. Флаг `--allow-draft` выдаёт явно помеченный черновик. Ревью по оригиналу и проверка полноты фиксируются отдельно от технической сборки.

Актуальный формат: [Газпром — годовая книга](Газпром/Годовая_книга/Газпром.xlsx), листы2023/2024/2025. Сейчас содержит шесть полных выверенных цитат (14 проверяемых частей); полный корпус не завершён. В ячейках показаны полные цитаты и краткие факты источников. Клик по цитате ведёт к отчёту, по пояснению — к основному внешнему источнику; остальные URL и уточнения сохранены в примечании ячейки.

Завершённая внешняя проверка требует поисков по Росприроднадзору, Ростехнадзору, судебным делам, авариям и инцидентам в СМИ. Старые результаты без этой проверки не проходят текущую приёмку. Неподтверждённое не превращается в ложь: Правда/Неправда/Частично правда применяются по доказательствам, Не установлено и Непроверяемое заявление сохраняют открытый смысл.

Повторная проверка: одна полная цитата — одна строка с оценкой всех существенных частей. Повторы отдельных атомов не допускаются; их нужно объединить с сохранением аспектов. В причине нет «Вывод:», а точность даты/периметра определяется самим утверждением, не дополнительными непрошенными условиями.
