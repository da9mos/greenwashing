В каждом из четырёх документов обработана одна партия страниц 5–8. Всего 282 кандидатных заявления, прошедших проверку структуры профиля v3.1. Независимая сверка полноты этих страниц и внешняя проверка остальных строк открыты.

По одному заявлению из экологического отчёта завершён внешний поиск. ОПЕК показывает, что Россия лидировала по доказанным запасам природного газа на конец 2023 года. МЭА сравнивает жизненный цикл газа с углём. Сопоставимых данных о «самом чистом и доступном» ресурсе для всех альтернатив в формулировке отчёта не найдено. В строке указан статус «Недостаточно сопоставимых данных». [ОПЕК, таблица 9.1](https://www.opec.org/assets/assetdb/asb-2024.pdf#page=78) · [МЭА, Global Methane Tracker 2025](https://www.iea.org/reports/global-methane-tracker-2025/key-findings)
