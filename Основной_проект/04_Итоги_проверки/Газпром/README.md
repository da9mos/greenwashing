# Оценка заявлений — Газпром

[Черновик Excel с четырьмя листами](Оценка_заявлений_Газпром_черновик.xlsx) · [CSV на каждый отчёт](CSV/).

В каждом из четырёх документов обработана одна партия страниц 5–8. Всего 282 кандидатных заявления, прошедших проверку структуры профиля v3.1. Независимая сверка полноты этих страниц и внешняя проверка остальных строк открыты.

В экологическом отчёте за 2023 год начата проверка заявления о природном газе. МЭА сравнивает жизненный цикл газа с углём. Этот результат виден в пояснении, а широкая формулировка о «самом чистом и доступном» ресурсе и блок о запасах требуют дополнительной проверки. [МЭА, Global Methane Tracker 2025](https://www.iea.org/reports/global-methane-tracker-2025/key-findings)

В [материалах пилота](Материалы_пилота/) сохранены четыре структурно проверенных ответа, запись поиска по новому прогону. Прежняя [пилотная книга на 719 строк](../../../Старая_версия/Локальный_пилот_Газпрома/Газпром_2023_ESG_пилот.xlsx) доступна в архиве.
