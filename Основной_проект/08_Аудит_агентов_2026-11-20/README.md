# Проверка проектных агентов Сбера

Проверка 20.11.2026 выполнена строго по трём существующим инструкциям проекта: PDF_TO_MD_AGENT.md (режим независимой проверки Codex), esg_agent_v3_1.md и FACT_CHECK_AGENT.md. Отдельный универсальный исследователь в результат не включён.

## Вывод

Агенты работают как проверяемый прототип. Найденные ошибки в числовых доказательствах, сборщике статусов и исполнении внешнего исследования исправлены. Производственная готовность всего корпуса и точность на независимом человеческом эталоне этой проверкой не подтверждены.

- [Проверка PDF](01_PDF/Аудит_PDF_агента.md): четыре цитаты реально сверены по растрам; три словесные ошибки в Markdown адресно исправлены. Старый вход сохранён, изменённые партии подлежат повторному извлечению.
- [Проверка ESG](02_ESG/audit.md): четыре составные цитаты разделены на восемь самостоятельных тезисов. Исправлены numeric substring, ложная нарезка numeric evidence, закрытие coverage при неустановленном числовом контексте и пропуск pending_classifications в сборщике.
- [Проверка фактов](03_Фактчекинг/audit.md): живой поиск по четырём исходным цитатам и выводы по восьми атомам. Штатный экспорт atomic_export имеет research_complete, total=8, unfinished=0. Семь исходов insufficient_evidence и один not_verifiable. Это завершённое ограниченное исследование, а не подтверждение истинности восьми тезисов.
- [Excel-пример](Результат/Excel/Газпром_пример_полного_цикла_8_тезисов.xlsx): один лист, шесть столбцов, у каждой строки результат исследования и ссылки. Это восемь выбранных тезисов, не полный отчёт Газпрома.

## Исправление запуска

Ранее массовый контроллер выполнял только извлечение и останавливался перед фактчекингом. Режим `--stage all` теперь чередует оба проектных агента; независимая сверка с PDF остаётся условием категорических выводов. `search_claim` хранит исходный план, нативный веб-журнал и принятые ревизии, а не удаляет их вместе с временной папкой. Программная проверка и реальное исследование отражаются раздельно.

Подробный след сохранён в `01_PDF/`, `02_ESG/`, `03_Фактчекинг/` и `Проверка/`. Старые модельные ответы и исторические результаты не переписаны новой оценкой.

## Подтверждение исправлений

143 технических теста пройдено (PDF 38, ESG 55, фактчекинг 23, контроллер 8, экспорт 2, worker 17). Excel повторно импортирован: один лист, восемь исследованных строк, шесть столбцов, все значения и ссылки сохранены. Файл открыт в Microsoft Excel.

Живой CLI-прогон обвязки дополнительно выявил повторный ingest одной ревизии: модель уже сохранила пакет по проектной инструкции, а обвязка пыталась принять его повторно. Теперь совпадающий пакет принимается как уже сохранённый, а иной пакет той же ревизии отклоняется. Строгая неизменяемость истории сохранена. Реальный частичный результат восстановлен из checkpoint без повторного поиска; двенадцать нативных событий веб-поиска подтверждены, полный корпус этим не объявлен исследованным.

Для ESG-запуска добавлена одна попытка исправления JSON по точной ошибке валидатора в общем лимите до 900 секунд; оба непринятых ответа сохраняются. Обход PDF-gate через кэш закрыт: категорический результат без входной проверки PDF не используется как готовый, исходная ревизия остаётся в истории.
