## Реестр по всем 30 компаниям

Архивный прогон v1 охватил 92 отчёта за 2023-2025 годы и дал 928 заявлений из предварительно отобранных предложений. Цитаты сверены с сохранённым текстом. По оригиналам раньше сверили 30 PDF-цитат и одну TXT-цитату. Все 928 строк доступны в [исходном CSV](../../../Старая_версия/03_итерация_3_пайплайн/data/out/claims.csv) и в [Excel по 30 компаниям](ESG_30_компаний_v1.xlsx). В Excel добавлены фильтры и лист охвата. В девяти цитатах служебные символы заменены пробелами для отображения. Исходный CSV сохраняет их как в архиве.

В опубликованном снимке профиля 3.1 подготовлены партии всех 92 отчётов. Принято 66 из 3 716 партий, получено 3 497 кандидатов. Это отдельный незавершённый прогон. [Статус на проверенном коммите](../../06_Прогон_корпуса/status.json)

Валидатор сверяет доказательные фрагменты с Markdown и учитывает каждый целевой блок. Папка 03 готовит очередь проверки достоверности утверждений по документам и фактам.

Проверены обратное чтение и постановка всех 10 записей в очередь этапа 03 через JSON.
- [Excel](ESG_пилот.xlsx) содержит лист «Заявления» с 10 принятыми записями, лист «Сверка» с 12 решениями и лист «Ручная проверка» с наблюдениями Григория по 12 случаям. Шапки закреплены, длинные цитаты и комментарии переносятся внутри ячеек.

## Скорость и качество

В экспорте и очереди рабочий каталог и методика теперь проверяются один раз на отчёт. До изменения для каждого ответа повторно читались, хешировались и разбирались файлы отчёта и партий. Валидатор числовой опоры теперь отклоняет значение с отброшенной стрелкой направления, если стрелка есть в Markdown. В обычном CSV появились источник, количественные поля и точные опоры в `evidence_json`.

| Полный Markdown | Партий | До, с | После, с | Ускорение |
| --- | ---: | ---: | ---: | ---: |
| Норникель 2023 | 62 | 34,370 | 0,994 | 34,6 раза |
| ЛУКОЙЛ 2023 | 29 | 5,096 | 0,213 | 23,9 раза |
| Северсталь 2023 | 74 | 25,045 | 0,525 | 47,7 раза |

Медиана трёх локальных запусков каждой версии на общих входах. Для каждой партии использован технический ответ без заявлений с разбивкой полного покрытия на `pending`. В каждом сравнении совпали выданные JSON со списками заявлений и покрытия. Это время проверки и экспорта без вызова модели. Замер повторяется командой `python benchmark_export.py`. В итоговом комплекте 67 тестов этапа 02, 41 тест этапа 03 и 6 тестов запуска worker. Контроллер 06 требует модуль `fcntl`, отсутствующий в Windows.

Первоначальные десять случаев отобраны для диагностики и использованы для правки правил. После ручного просмотра Григория добавлены две отдельные записи о цели и прогрессе по приоритетным загрязняющим веществам ЧерМК. Затем проведено [сравнение промптов на трёх других отчётах](../Проверка_агента_2026-11-22/Сравнение/Отчёт_сравнения.md). Улучшение точности и скорости генерации на этой выборке не подтверждено.

Три [изображения оригиналов](Страницы_оригиналов) приложены для проверки пилотных решений. Повторная сборка Excel по всем 30 компаниям доступна командой `python build_archive_workbook.py`, нужен пакет `xlsxwriter`.

## Ручная проверка Григория

Григорий просмотрел все десять первоначальных случаев и подтвердил C5 и C6 по второй строке таблицы на странице 182 отчёта «Северстали». Его наблюдения и итоговая интерпретация источника сохранены в [журнале ручной сверки](Ручная_сверка_Григория.json). По L1 он предварительно согласился и попросил разъяснить сравнение периодов. Решение по L3 сохраняет основную G и дополнительную E. Разметка всего содержания страниц и всего корпуса остаётся отдельной задачей.

Для повторной выгрузки из этой папки запустите `python build_pilot.py --factcheck-json claims.json`. Готовый [claims.json](claims.json) подходит для `factcheck.py prepare`. Для пересборки Excel сначала создайте данные командой `python build_pilot.py --workbook-data workbook.json`, затем выполните `node build_workbook.mjs workbook.json ПУТЬ_К_NODE_MODULES`. Нужен пакет `@oai/artifact-tool`.
