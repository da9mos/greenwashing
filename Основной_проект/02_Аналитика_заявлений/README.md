Из корня основного проекта подготовьте весь корпус командой:

```sh
python3 02_Аналитика_заявлений/Агент/scripts/prepare_corpus.py --out ../work/извлечение
```

Добавьте `--report-id GAZP-2023-ЭО` для отдельного документа. Партия хранит точные блоки и соседний контекст. Передайте модели только JSON партии и входной комплект правил из очереди или команды `model-files`. Научные статьи используются при составлении и пересмотре методики. Сохраните ответ отдельно, проверьте его командой `check` и после обработки всех партий соберите отчёт командой `export`. Передайте `claims.json` агенту фактчекинга, а `coverage.csv` используйте для независимой сверки пропусков. Сохраняйте рабочую папку для возобновления.

Продолжение с места остановки: `python3 02_Аналитика_заявлений/Агент/scripts/queue_corpus.py ../work/извлечение ../work/ответы --limit 20`. Скрипт перечисляет задания для модели и проверяет сохранённые ответы. Для ответа, где модель указала количественное поле без дословной опоры или исключила использованный блок, запустите `review_response.py РАБОЧАЯ_ПАПКА ОТВЕТ ЧЕРНОВИК_РЕВИЗИИ`. Он оставляет спорное поле или блок открытым, сохраняя исходный ответ и проверяя исправленный контракт.
