# Аналитика ESG-заявлений

[Профиль 3.1](Агент/README_v3_1.md) · [правила E/S/G и типы заявлений](Агент/Методика_выявления_ESG_v3_1.md) · [научные статьи](Научные_статьи/README.md).

Из корня основного проекта подготовьте весь корпус командой:

```sh
python3 02_Аналитика_заявлений/Агент/scripts/prepare_corpus.py --out ../work/извлечение
```

Добавьте `--report-id GAZP-2023-ЭО` для отдельного документа. Партия хранит точные блоки и соседний контекст. Дайте модели инструкцию, кодбук и JSON партии. Сохраните ответ отдельно, проверьте его командой `check` и после обработки всех партий соберите отчёт командой `export`. Передайте `claims.json` агенту фактчекинга, а `coverage.csv` используйте для независимой сверки пропусков. Сохраняйте рабочую папку для возобновления.
