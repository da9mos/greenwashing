# Научные источники: analytics

Реестр основан на проверке28 исходных библиографических записей18.11.2026. В этом разделе только научные работы; стандарты/рейтинговые методики не выдаются за статьи. Read sections/abstract означает ограниченный охват чтения, а не полный текст. Правила агента в колонке agent_rule — наша операционализация, а не дословные научные законы.

Статья и авторский артефакт (model card/ESG9) различаются. Методическая статья не является доказательством корпоративного факта. Неподтверждённость не равна лжи/гринвошингу. Основная/дополнительная буква и атомизация требуют собственной валидации.
