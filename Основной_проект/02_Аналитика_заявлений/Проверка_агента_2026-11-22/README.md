# Слепая разметка и сравнение агента

Три страницы отобраны из других отчётов до запуска сравниваемых промптов. В прежнем эталоне `sentences.jsonl` и `sentences_commit.jsonl` этих страниц не было.

1. [КАМАЗ 2024, PDF 120](KMAZ_PDF_120.png) - текст о внутреннем аудите.
2. [АЛРОСА 2024, PDF 177](ALRS_PDF_177.png) - четыре таблицы персонала за 2021-2024 годы.
3. [Полюс 2025, PDF 88](PLZL_PDF_88.png) - текст, графики и сноски об энергии и выбросах.

## Результаты

- [Промпт для независимой модели](Промпт_для_другой_модели.txt) и [исходный ответ GPT-6.1 Sol](Разметка_GPT-6.1-Sol.md).
- [Протокол сверки](Протокол_сверки.md), [реестр страниц с SHA-256](Реестр_страниц.json) и [итоговый эталон CSV](Эталон_ESG.csv). 167 единиц для оценки и 1 спорная. Эталон после модельной сверки требует отдельного человеческого подтверждения, если используется как окончательная человеческая разметка.
- [Отчёт сравнения](Сравнение/Отчёт_сравнения.md), [сводка JSON](Сравнение/Результаты.json) и [проверенное сопоставление CSV](Сравнение/Проверенное_сопоставление.csv).

Содержимое исходных ответов и промптов сохранено, включая типографику источников. В папке `Сравнение` находятся шесть ответов JSON, их метаданные и полные входы. Журналы упакованы в [ZIP](Сравнение/Журналы_запусков.zip). Файлы с `old` относятся к профилю 3.1 из `c5ec442`, с `new` - к обновлённому промпту.

## Воспроизведение

`python Сравнение/итог.py` заново строит предварительное сопоставление из сохранённых ответов, применяет проверенные уточнения и обновляет сводку. Внешние запросы для этой команды не требуются.

`python Сравнение/запустить.py --out НОВЫЙ_КАТАЛОГ` повторяет шесть модельных вызовов по сохранённым входам и настройкам. Нужны авторизация Codex и доступ к указанной модели. Ответы нового запуска появятся в отдельном каталоге.

`python Собрать_эталон.py --reports-dir ПАПКА_ОРИГИНАЛОВ_PDF` проверяет опоры и заново собирает CSV эталона. Нужен PyMuPDF и файлы `KMAZ-2024-ОУР.pdf`, `ALRS-2024-ОУР.pdf`, `PLZL-2025-ИО.pdf` с хешами из реестра страниц. Полные PDF берутся из реестра отчётов проекта.

В сравнении обе версии получили исходные изображения. Отдельный запуск штатного извлечения только по Markdown необходим для оценки потерь на подготовке текста. Подробности и ограничения приведены в отчёте.
