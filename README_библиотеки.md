# Сбер гринвошинг: детектор гринвошинга в нефинансовой отчётности

Проект 2 практикума ESG (Сбербанк, Уральский банк, CIB; куратор Камилла). Сравниваем ESG-заявления 30 российских компаний (отчёты 2023–2025, блоки E, S и G) с цифрами из тех же отчётов и с внешними фактами: штрафами, авариями, несчастными случаями, судами, новостями. Каждое заявление получает класс «подтверждено / декларативно / противоречит фактам», из классов складывается индекс риска компании. Это риск-сигнал для внутренней аналитики банка, а не обвинение.

*Обновлено 12.11.2026 (вечером: конвейер без API-ключа).*

## Решения, которые уже приняты

1. **Охват:** все 30 компаний «Итоговой выборки — 30 компаний» (6 отраслей), отчёты 2023–2025, ESG целиком (E, S, G). Не «только экология» и не «пилот на трёх компаниях». На слайде 19 допускается деление E / S+G между двумя командами, но мы делаем всё; с командой Арины Ким согласуем только общую схему классов и формат таблиц.
2. **Кто делает работу:** конвейер выполняет Claude, у каждого этапа есть владелец из команды (см. «Задачи_команды»). Григорий вручную ничего не размечает.
3. **Второй разметчик (критерий 4):** вторая модель с другим промптом; спорные случаи решает Егор Д. В отчёте честно пишем, что каппа посчитана между двумя моделями.
4. **Ключи таблиц:** код компании из 4 латинских букв, `NORN-2024-017` для заявлений, `F-NORN-003` для фактов.
5. **Ограничения среды:** капчу на kad.arbitr.ru не обходим (суды через sudact.ru и вручную); часть российских сайтов может требовать российский интернет; доступа к GigaChat нет (запасной вариант — другая модель Claude); папка Google Drive не подключена, файлы скачиваются по `drive_id`.
6. **Без API-ключа (12.11.2026):** ключ `ANTHROPIC_API_KEY` не заводим и за API не платим. Работу с текстом Claude делает в потоках проекта партиями, скрипты делают только механику и собирают таблицы из сохранённых ответов. Воспроизводимость — через сохранённые ответы и журнал партий, а не через `temperature = 0`. Подробно в `Конвейер_без_API.md`.

## Как работать в проекте

- **На компьютере Григория (приложение Claude, вкладка Code):** каждый новый чат открывать в папке `C:\Users\User\Desktop\Гринвошинг`. Claude сам прочитает `CLAUDE.md` и память проекта, объяснять заново не нужно. Все чаты этой папки собраны в боковой панели в одну группу.
- **Для остальных участников (claude.ai, проект «Сбер гринвошинг»):** в файлы проекта загрузить этот README, `Задачи_команды.md`, общий план и `companies.csv`. Тогда любой новый чат в проекте знает задачи и решения.
- **Связать этот локальный чат с проектом на claude.ai:** в этом чате набрать `/send-to-project` и выбрать «Сбер гринвошинг». Команда отправит в проект сообщение со ссылкой на этот чат.
- **Правило обновления:** когда меняется решение, правим `Задачи_команды.md` или общий план и дописываем строку в «Историю чатов и решений». Старые файлы не удаляем, а помечаем как устаревшие.
